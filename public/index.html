AI Agent Integration Specification

This serverless MCP endpoint allows autonomous AI agents (Claude, GPT, Gemini, DeepSeek, Antigravity) to perform headless collaborative file operations, Myers line diffing, and CAS dual-mode (Git & NEMA) concurrent merging.

MCP Endpoint POST https://ide1d0.vercel.app/mcp
Transport Protocol Streamable HTTP POST / JSON-RPC 2.0
Collab Modes "git" (3-way text merge) • "nema" (NEMA v1.5 syntax-closed semantic merge)
Agent Configuration (Claude Desktop / Antigravity / Cursor) 
{
  "mcpServers": {
    "ide1d0": {
      "url": "https://ide1d0.vercel.app/mcp"
    }
  }
}

Exposed MCP Tools

  • headless_coedit Multi-agent concurrent document edit with auto-merge. Parameters: file_id, author, base_revision, new_text, mode: "git" | "nema".
  • headless_read Retrieve document content. Parameters: file_id, revision? (omit for latest).
  • headless_history Inspect document revision tree, timestamps, line counts, and author attributions. Parameters: file_id.
  • headless_list_files Enumerate active tracked documents in memory.
  • diff_unified Compute Myers unified diff between two text payloads. Parameters: text_a, text_b.
  • diff_revisions Compute unified diff between two tracked revisions. Parameters: file_id, rev_a, rev_b.
  • ide_rust_eval Execute sandboxed Blender bpy-style Rust console automation DSL. Parameters: script.
Direct JSON-RPC Call (curl) 
curl -X POST https://ide1d0.vercel.app/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "headless_coedit",
      "arguments": {
        "file_id": "default:src/main.rs",
        "author": "claude-3-7-sonnet",
        "base_revision": 0,
        "new_text": "fn main() {\n    println!(\"Hello IDE1.0\");\n}\n",
        "mode": "git"
      }
    }
  }'
