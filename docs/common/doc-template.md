# 文档模板 (IPA 共通フレーム2013 互換)

> **適用範囲:** IDE1.0 IDE Shell 全プロジェクト文档
> **準拠標準:** IPA 共通フレーム2013 (Software Engineering Center, 2013/03/04 発行)
> **CF2013 構造:** プロセス → アクティビティ → タスク → 注記 の 4 階層

## テンプレート使用規則

### 1. 4階層構造 (必須)

すべてのドキュメントは以下の 4 階層構造で記述する:

```
プロセス
 └─ アクティビティ
     └─ タスク
         └─ 注記
```

### 2. 编号规则

- プロセス: `DOC-NN` (NN は 2桁数字, 例 `DOC-01`)
- アクティビティ: `DOC-NN.A` (例 `DOC-01.A`)
- タスク: `DOC-NN.A.B` (例 `DOC-01.A.1`)
- 注記: `DOC-NN.A.B.C` (例 `DOC-01.A.1.i`)

### 3. 必須セクション (各ドキュメント共通)

```markdown
# [DOC-NN] [ドキュメント名]

> **メタ情報:**
> - **ドキュメント ID:** DOC-NN
> - **バージョン:** vX.Y.Z
> - **作成日:** YYYY-MM-DD
> - **最終更新:** YYYY-MM-DD
> - **担当プロセス:** [CF2013 主プロセス名]
> - **準拠標準:** IPA 共通フレーム2013 §[N]
> - **ステータス:** Draft / Review / Approved / Superseded

## 1. 概要

(ドキュメントの目的・スコープ・対象読者)

## 2. プロセス定義

**プロセス ID:** DOC-NN
**プロセス名:** [CF2013 主プロセス名]
**目的:** [プロセスの達成目標]
**開始条件:** [このプロセスが開始する要件]
**終了条件:** [このプロセスが完了する基準]

## 3. アクティビティ

### DOC-NN.A アクティビティ 1
- 目的
- インプット
- アウトプット
- 担当役割

### DOC-NN.B アクティビティ 2
...

## 4. タスク

### DOC-NN.A.1 タスク 1
- 手順
- 成果物
- 検証方法

### DOC-NN.A.2 タスク 2
...

## 5. 注記

### DOC-NN.A.1.i 注記 1
(参考情報・補足・例示)

## 6. 関連ドキュメント

- [関連ドキュメント 1](path/to/doc.md) — 参照関係
- [関連ドキュメント 2](path/to/doc.md)

## 7. 改訂履歴

| 版 | 日付 | 担当 | 変更内容 |
|---|---|---|---|
| v0.1.0 | YYYY-MM-DD | [Name] | 初版 |
```

### 4. 言語ポリシー

- **本文:** 中文 (zh-CN) メイン, IPA 用語 は 日本語 保留
- **タイトル/ID:** 第 1 語 英語, 第 2 語 中文
- **コード例:** 英語コメント + 中文说明
- **3 言語キーワード:** 各ドキュメント冒頭で列挙

### 5. トレーサビリティ

各ドキュメントは以下をリンクすること:
- 親プロセス → 子アクティビティ
- 要件 → 設計 → 実装 → テスト
- リスク → 対応 → 結果
