# 编号系统 (CF2013 準拠)

> **適用範囲:** IDE1.0 IDE Shell 全ドキュメント
> **準拠:** IPA 共通フレーム2013 §6「共通フレームとガイダンスの見方」
> **核心原則:** CF2013 は「文書/書式を規定しない」が, プロセス体系は 4 階層構造で識別

## 4 階層構造 (CF2013 §5)

```
プロセス (Process)
 └─ アクティビティ (Activity)
     └─ タスク (Task)
         └─ 注記 (Note)
```

## 编号フォーマット

| 階層 | フォーマット | 例 |
|---|---|---|
| プロセス | `DOC-NN` | `DOC-01` |
| アクティビティ | `DOC-NN.A` | `DOC-01.A` |
| タスク | `DOC-NN.A.B` | `DOC-01.A.1` |
| 注記 | `DOC-NN.A.B.C` | `DOC-01.A.1.i` |

> **NN:** 2 桁数字 (01 ~ 99)
> **A:** 大文字英字 (A ~ Z, 最大 26)
> **B, C:** 数字 (1 ~ 9)

## ロール責任

| ロール | 责任 |
|---|---|
| **Author** | ドキュメント作成 |
| **Reviewer** | 技術レビュー (1 次) |
| **Approver** | 承認 (PM/Architect) |
| **Distributor** | 配布・通知 |
| **Archivist** | 保管・履歴 (DOC-17 参照) |
