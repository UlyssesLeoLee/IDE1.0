## 1. 基线适用与裁决

本文件将用户已经确认的 v2.0 要件冻结为 FR-001～FR-049、NFR-001～NFR-028 的**摘要索引**。原始聊天中 v2.0 文档仍是上位完整基线；此包包含可离线使用的要件摘要、设计裁决及测试映射。凡测试/设计解释冲突，按「用户批准的最新要件 → 变更记录 → 本包设计假设」排序处理，不将设计偏好篡改为用户已批准要件。

**重要区分**：P0=首期必须；P1=增强；P2=独立可选。UT/IT/ST 用例包含 P1/P2 的设计预留，尚未实现的功能在执行时标记 `Not Applicable/未纳入本迭代`，不得记作通过。

## 2. 功能要件索引

| FR | 功能 | 优先级 | 归属模块 | 具体行为约束 | 验收重点 |
|---|---|---|---|---|---|
| FR-001 | 原生编辑能力保留 | P0 | HOST | 在宿主文本缓冲区完成光标、选区、撤销、查找与保存；MD 插件不持有第二份可编辑权威缓冲区 | 宿主原有编辑和撤销语义不变 |
| FR-002 | 文件类型识别 | P0 | SESSION | 依据扩展名与手动覆盖识别 .md/.markdown；切换类型时释放不需要的状态 | 非 Markdown 不启动专用渲染；手动切换有效 |

| FR-004 | 宿主功能复用 | P0 | HOST | 搜索、Grep、宏、键绑定、标签页复用宿主实现 | 不新建平行文本核心 |

| FR-016 | 列表编辑 | P0 | COMMAND | 识别缩进及列表层级，支持类型转换与升降级 | 维持子项及缩进 |

## 3. 非功能要件索引

| NFR | 分类 | 要求/初始阈值 |
|---|---|---|
| NFR-001 | 非MD零渲染 | 非 Markdown 文件不创建 Markdown 专用渲染进程或 WebView |
| NFR-002 | 普通文本启动增量 | 普通文本冷启动 P95 增量 <=100 ms |
| NFR-003 | 非MD常驻内存 | MD 功能未激活时增加的常驻内存目标 <=10 MiB |
| NFR-004 | 1MiB 源码打开 | 1 MiB Markdown 源码打开 P95 <=1 s |
| NFR-005 | 输入延迟 | 1 MiB Markdown 普通输入可见响应 P95 <=50 ms |
| NFR-006 | 预览冷开 | 1 MiB Markdown 基础预览首次打开 P95 <=2 s |
| NFR-007 | 按需高级模块 | Mermaid/数学/AI 不调用则不加载 |
| NFR-008 | 避免阻塞渲染 | 解析预览不得长时间同步阻塞 UI |
| NFR-009 | 关闭资源释放 | 关闭预览后释放可释放的专属资源 |
| NFR-010 | 大文件降级 | 资源压力或超阈值时能安全退回源码模式 |
| NFR-011 | 局部处理 | 文档更改优先更新受影响节点 |
| NFR-012 | 索引增量 | 大纲/预览/检查可增量更新 |
| NFR-013 | 图表懒更新 | 普通字符输入不无条件重渲染全部图表 |
| NFR-014 | 屏外延迟 | 预览屏外内容采用虚拟化或其他低开销策略 |
| NFR-015 | 零编辑零写回 | 打开/预览/切换不修改磁盘文件 |
| NFR-016 | 未知语法保留 | Front Matter/HTML/未知围栏保真 |
| NFR-017 | 无隐式格式化 | 保存及切换不自动规范化全部MD |
| NFR-018 | 冲突与编码 | 外部修改及编码损失必须显式处理 |
| NFR-019 | 键盘可访问 | 主要操作可通过键盘完成 |
| NFR-020 | 快捷键冲突检测 | 冲突可识别且可重新映射 |
| NFR-021 | IME稳定性 | 中日 IME 组合输入与候选词不受干扰 |
| NFR-022 | 主题/DPI | 遵守宿主字体缩放、主题和DPI |
| NFR-023 | 入口可发现 | 高级功能可搜索但非常驻 |
| NFR-024 | HTML预览安全 | 预览对不可信HTML和脚本进行隔离过滤 |
| NFR-025 | 禁止自动脚本 | 不默认执行用户MD中的脚本或命令 |
| NFR-026 | AI数据外发授权 | 本地文档无授权不外传 |
| NFR-027 | 远程资源访问 | 远程图片链接遵循访问策略 |
| NFR-028 | 插件权限隔离 | 插件文件/进程/网络权限不可绕过 |

## 4. 上位业务不变量（INV）

| 编号 | 不变量 | 证据方式 |
|---|---|---|
| INV-01 | 文本缓冲区由宿主控制，Markdown 插件不创建第二个可编辑权威缓冲区 | HostAdapter事务日志、文件hash |
| INV-02 | 视图切换不产生隐式写回、隐式全篇格式化 | 比较修改计数、SHA-256、DirtyFlag |
| INV-03 | 非Markdown文本场景不初始化预览/渲染子进程 | 进程采样+模块加载记录 |
| INV-04 | 工具栏/快捷键/Slash/插件使用同一 CommandBus | 同命令同结果与撤销ID |
| INV-05 | 不支持或未知语法的内容被保留，不因WYSIWYG转换丢失 | 往返保真字节比对 |
| INV-06 | 插件或可选渲染器崩溃不影响宿主原生保存 | 故障注入 |
| INV-07 | 默认顶层工具入口最多8组，低频工具渐进披露 | UI视觉检查 |
| INV-08 | 外发文件/网络/进程权限由宿主安全策略控制 | 安全拒绝日志与越权测试 |

## 5. 尚未确认的决策（不可伪称实测）

- **TBD-001** 宿主是实际 Sakura Editor 还是自研相似 IDE；其插件生命周期、文本缓冲与UI扩展能力待 POC。
- **TBD-002** 编辑器位置计数使用 UTF-8 字节、UTF-16 code unit、Unicode scalar 或其他模型。
- **TBD-003** Windows 首期支持矩阵、应用沙箱可用性、WebView2 Runtime 是否预装。
- **TBD-004** Markdown 解析器与 GFM 方言版本、语言中立 AST 范围。
- **TBD-005** 非功能数值属于初始目标，须真实基线实测后批准。
- **TBD-006** P1/P2 产品里程碑与预算、是否包含 AI 提供方接口。

## 6. 需求变更流程

提出 CR → 影响 FR/NFR、BD/DD、UT/IT/ST → 审核与裁决 → 更新追踪矩阵及版本 → 重测影响范围。不得仅修改源码而遗漏设计与测试。
