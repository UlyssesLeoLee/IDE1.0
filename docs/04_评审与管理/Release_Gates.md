# 发布门禁与交付判据

| Gate | 时点 | 通过证据 | 不通过后果 |
|---|---|---|---|
| G0 | 宿主适配POC | 实际API映射、编码/Undo/IME/面板/隔离可行性报告 | 停止或更换适配方案 |
| G1 | 基本设计冻结 | ADR、画面流、外部接口、需求映射评审记录 | 不进入核心实现 |
| G2 | 详细设计冻结 | Host契约、补丁算法、插件Schema、安全边界复核 | 不开放无约束插件 |
| G3 | UT完成 | 纳入P0用例100%执行且Pass、关键模块覆盖实测报告 | 不进入全量IT |
| G4 | IT完成 | 真实宿主集成，关键接口通过，无开放S1/S2 | 不进入系统验收 |
| G5 | ST完成 | P0与适用NFR合格，启动/内存/输入P95原始数据齐全 | 禁止发布 |
| G6 | 发布准备 | 残余风险批准、版本/变更/回滚/用户帮助齐全 | 不对外发布 |

P1/P2未纳入当前迭代时必须正式标注N/A并保留设计追踪，不能作为Pass计入。
