# G0 — Sakura风格宿主可行性验证清单

每个项目必须关联真实宿主版本、源码/SDK证据、POC日志、责任人与通过日期。不得仅凭接口草案判Pass。

| POC ID | 阻断项 | 最小验证动作 | 通过判据 |
|---|---|---|---|
| POC-01 | 原生Buffer接口 | 打开UTF-8、Shift-JIS、Emoji文档，返回原始文本与位置 | 字符和位置正确，无二次权威Buffer |
| POC-02 | 原子多范围Undo | 用实际宿主API执行2处非相邻补丁，再Undo/Redo，注入第二步失败 | 全提交或全回滚；单逻辑Undo；已有Undo链不受损 |
| POC-03 | 编码/BOM/EOL | 打开FX-02/03/14，预览、切换模式、保存及冲突处理 | 无编辑零字节变化；需转换时明确提示 |
| POC-04 | IME及输入焦点 | 日中IME composition期间试触发Slash/浮动工具 | 不截断组合输入、不抢焦点 |
| POC-05 | 宿主UI可扩展性 | 加载/收起工具栏、对齐多DPI浮动面板 | 可访问，宿主原生面板/编辑不受损 |
| POC-06 | 插件OS隔离 | 限制令牌/AppContainer/其他机制测试工作区外读写、联网及进程创建 | OS层拒绝越权，插件退出宿主不崩溃 |
| POC-07 | 受控预览 | 无WebView/预览崩溃/不可信HTML/离线环境 | 源码始终可编辑，无脚本/远程请求越权 |
| POC-08 | 性能基线 | 裸宿主与扩展版运行≥30轮启动、≥500次输入，记录P95 | 按NFR阈值初步达标，否则提出CR |
| POC-09 | Worktree身份 | 相同路径名分别在两个Worktree打开编辑 | 不共享错误索引或引用映射 |
| POC-10 | 插件惰性与卸载 | 注册100个Manifest但不运行；启动一个，再禁用 | 启动时无多余worker；关闭后资源释放 |

**停止条件**：POC-01/02/03/04/06失败，需调整架构或限制声明的P0功能；不得默认为已实现。
