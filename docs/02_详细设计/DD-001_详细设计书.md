## 2. DDS-01 HOST 宿主适配层（FR-001/004）

### 2.1 内部结构

`IEditorHost` 定义获取Buffer、Snapshot、Selection、Undo、保存/文件事件和主线程UI挂接接口。实际宿主侧需实现 Adapter，绝不将 SDK 不具备的能力假定存在。

- `HostCapabilityDetector`：初始化时枚举宿主真正支持的接口；不足时按特性降级。
- `DocumentEventBroker`：将宿主事件转换为`Opened/Changed/Saved/ExternalChange/Closed`，绑定 `sessionId + version`。
- `HostPositionCodec`：将解析器UTF-8字节offset与宿主原生offset相互转换，缓存行偏移，验证合法UTF-8字符边界。
- `HostEditGate`：在宿主主线程提交事务，并返回明确的 `undoId` 和 `nextVersion`。

详见：[Host Adapter 契约](contracts/host_adapter_contract.md)。

### 2.2 前置/后置条件

**前置**：Buffer可写；selection边界合法；`expectedVersion == currentVersion`；未处于禁止修改的 IME 中间态。

**后置成功**：所有 edits 成功；version递增一次；宿主撤销可恢复原始文本；结构索引失效区间已登记。

**后置失败**：文本、选区、dirtyFlag和撤销栈的可观察状态不得出现部分提交。

### 2.3 Offset转换算法

1. 获取宿主原生坐标语义；未知语义视为 POC 阻断项。
2. 从快照构建 lineStart 与 `utf8Byte ↔ hostOffset` 映射，必要时只针对涉及行建立表。
3. 转换每个Range的首尾，并拒绝分割 UTF-8多字节或 UTF-16代理对的范围。
4. 对换行采用原始文本真实长度计算；禁止统一假设 LF或CRLF。
5. 转换后的offset在同版本快照中做往返验证，否则返回INVALID_RANGE。

## 3. DDS-02 SESSION 文档会话（FR-002/024/029）

### 3.1 DocumentKey与生命周期

`DocumentKey={workspaceId,hostBufferId,canonicalUri}`；打开时创建一次 Session，关闭时取消其解析任务/预览任务/诊断订阅。文件重命名通过宿主事件原子变更URI，避免旧链接污染其他 Worktree。

状态：PlainText、MdSource、MdSplit、MdImmediate(P1)。视图切换只能更改 `mode/layout/cache`，**不得产生 EditTransaction、保存、自动全篇格式化**。

### 3.2 事件处理

| 事件 | 处理 | 幂等/一致性 |
|---|---|---|
| Opened | 依据扩展名/覆盖策略选择模式 | 相同Buffer不重复创建Session |
| TextChanged | version+1、记录DirtyRanges、取消旧任务 | 只接受较新版本结果 |
| Saved | 更新diskFingerprint、dirty标记依据宿主 | 不主动更改编码 |
| ExternalChange | 标记冲突/交由宿主合并UI | 禁止插件自行覆盖 |
| Closed | 取消异步任务、释放引用与UI | 不影响其他Tab |
| WorktreeSwitch | 更换workspaceId、重新解析相对URI | 不复用其他工作树缓存 |

## 4. DDS-03 IO 文件完整性（FR-003）

### 4.1 编码模型

保留宿主记录的 `fileEncoding`, `BOM`, `EOL`, `mixedEolMap`（若可获得）。仅读/预览绝不写磁盘。插入字符前由宿主编码器执行可表示性检查；不能表示时显示“更换编码并保存副本/取消”的明确操作，不得自动生成问号替换字节。

### 4.2 Save冲突流程

1. 启动保存前获取磁盘指纹（mtime+size+必要哈希）并与打开基线比较。
2. 若宿主检测到外部修改，展示比较/重新加载/另存选项。
3. 只调用宿主原有 Save API，接收真实成功状态才将会话标记已保存。
4. 如果宿主API无法确保保真，禁止扩展直接绕过此限制写回。

### 4.3 保真判据

- 没有 EditTransaction 时，原始磁盘哈希保持完全相同。
- 有操作时，只允许目标范围与用户已确认的新增资源发生改变。
- Front Matter、未知HTML、未知围栏、表格管道符须按原文保留。

## 5. DDS-04 TOOL 工具导航（FR-005/006/008/009/010/013）

### 5.1 工具注册模型

`ToolDefinition(id,commandId,groupId,icon,rank,when,flags)`。注册器按 `group(rank), tool(rank)` 排序；重复ID拒绝并产生日志，不允许无声覆盖；默认顶层组 `select,text,list,insert,table,diagram,navigation,extension`，最多8个。

### 5.2 状态表达式

`ContextResolver` 的唯一输入为已版本化的 `ToolContext{docKind,selectionKind,nodeType,isReadonly,isIMEComposing,permissions,featuresEnabled}`。表达式为无副作用的布尔判定，禁止插件任意脚本在每次键击时执行。

### 5.3 工具显示约束

- 固定栏宽目标32~40px，根据宿主字体/DPI调整；单列图标。
- 默认只显示顶层组；长按/右键/箭头打开二级工具。
- 上下文浮层在选区存在且非IME时才出现；Esc/点击正文关闭。
- 插件只能向注册器提交元数据，不允许强行显示不可关闭的常驻大面板。
- 布局JSON为 `{version:1,orderedGroups:[...],pinnedTools:[...],hiddenTools:[...]}`；schema验证失败回退默认并备份损坏版本。

## 6. DDS-05 COMMAND 命令事务（FR-007/011/012/014/015/016/017/020/023）

### 6.1 标准执行链

`ResolveContext → VerifyCapability → VerifyPermissions → ResolveSelection → BuildEdits → NormalizeRanges → CompareVersion → Host.applyAtomic → UpdateIndex → NotifyPreview`。

### 6.2 RangeEdit 规范

1. 基于相同 `expectedVersion`快照计算半开区间 `[start,end)`。
2. 过滤非法范围与重叠范围，同位点插入按声明顺序合并。
3. 对非重叠补丁按起始位置降序应用，防止位移。
4. 一次用户命令形成一笔宿主撤销事务。
5. 若事务失败，返回错误且不得广播 `DocumentChangedSuccess`。

### 6.3 命令表

| Command ID | 前提 | 文本行为 | 边界 |
|---|---|---|---|
| md.text.bold | 有文本选区 | 包围/解包`**` | 不跨错误嵌套边界 |
| md.heading.setLevel | 当前段落 | 调整`#`数量 | 代码围栏中不可用 |
| md.list.makeTask | 可识别列表范围 | `- [ ]`格式 | 保留子列表缩进 |
| md.table.insert | 行列数≥1且≤策略上限 | 生成GFM表格 | 转义`\|` |
| md.code.fence | 选区 | 使用比内容反引号最长连续序列更长的围栏 | 空行/语言标签保留 |
| md.link.insert | URI权限有效 | `[label](target)` | 相对URI编码合法 |
| md.diagram.mermaid | MD上下文 | 插入 fenced mermaid template | 不启动渲染器 |
| md.undo | 宿主能力可用 | 直接调用宿主undo | 禁止自行维护第二undo |

### 6.4 Slash 检测算法

- 光标前触发点为 `/`，位于行首/空白后，非围栏/行内代码/URL/路径/IME composition。
- 延迟到不影响原生键入的事件边界才展示候选，不吞掉原始 `/` 字符。
- 选择候选时以一笔事务替换 slash 查询文本为目标元素；Esc关闭而保留原文。
- 插件只贡献搜索索引和已注册命令，不在每次键入启动执行体。

## 7. DDS-06 TABLE 表格操作（FR-018）

表格解析生成 `TableModel{rows,columns,align,sourceSpan,cellSpans}`，单元格划分必须理解转义`\|`和代码片段内管道符。可视化编辑首先只针对能够保真重建的 GFM 表格开放。若包含不支持的 HTML/混合扩展，退回源码编辑并保持原样。改变单格优先只生成最小行补丁，新增行列则替换表格范围并保留外围文本。

## 8. DDS-07 ASSET 图片资源（FR-019）

### 8.1 插入处理

1. 确定目标目录（工作区配置相对路径），拒绝未经授权的工作区外写入。
2. 清理输入文件名、校验 MIME 与扩展名；产生碰撞安全名称。
3. 将数据写到临时文件后原子重命名，确认成功后才提交Markdown引用补丁。
4. 引用文本以相对URI与正确转义生成 `![alt](relative/path)`。
5. 若源补丁提交失败且资源是本次新建、未被引用，执行安全清理或登记待清理项。

### 8.2 资源限制

图片预览必须限制单文件/尺寸资源预算；远程图片默认遵循工作区策略。不得自动访问任意 `file://` 本地机密文件。

## 9. DDS-08 PREVIEW 只读预览与图形（FR-021/022/025/026/027）

### 9.1 开启与缓存

预览开启时才装载只读渲染宿主（Windows候选 WebView2）；渲染输入为版本化快照；HTML由可信解析器产生，并对原文嵌入HTML采用允许列表。若 Runtime 缺失，关闭预览并给出非阻塞提示。

### 9.2 预览管线

`snapshot → parser/block/sourceMap → sanitize → local-resource resolver → safeHtml → preview renderer`。

- 仅显示用户可见区域及预加载邻近块，超长文档虚拟化策略可配置。
- 内容变更防抖建议100~150ms，可根据负载调节；旧版本任务取消或渲染结果丢弃。
- 图表按需；Mermaid源码由文档节点传入可信捆绑脚本的独立沙箱，限制URL、脚本注入、与宿主通信。
- 关闭后释放预览专用资源，保留轻量文本索引可按需缓存。

### 9.3 安全硬约束

- 纯Markdown里的任意`<script>`、事件属性、`javascript:`导航不允许执行。
- CSP、沙箱、资源协议必须配套执行；“只使用CSP”不足以替代HTML净化。
- Mermaid可信JS需要明确隔离，不能直接将原文拼入JavaScript字符串并求值。
- 默认不主动请求远程内容，必要时按工作区策略获得授权。

## 10. DDS-09 STRUCT 结构索引（FR-030/031/032/034）

### 10.1 Node 与来源映射

`StructureNode{type,nodeId,sourceByteRange,headingLevel,parentId,anchor,parserVersion}`。nodeId优先使用本次Session中稳定键，跨重排可能变化，不得当持久数据库主键。内部offset遵循UTF-8字节；提交编辑时必须经HostPositionCodec映射。

### 10.2 增量索引算法

1. `onTextChanged(version, dirtyRanges)`加入可取消队列。
2. 根据块边界定位受影响父段落/围栏/列表；难以可靠增量解析时回退到后台全量重建。
3. 工作线程在不可变快照上解析，输出带`version`的索引结果。
4. 主线程核对`version==current`才交换新索引；旧结果直接废弃。
5. 只广播受影响的 Outline/Reference/Diagnostics 更新。

### 10.3 锚点与引用

标题重复时按 GFM 规则生成唯一锚点；内部链接解析必须区分URL、工作区相对路径、锚点。工作区外访问遵守PermissionHost；失效仅标记诊断，不自动重写原文。

## 11. DDS-10 LINT 文档检查（FR-033）

Diagnostics 数据结构：`{ruleId,severity,sessionId,version,sourceRange,message,fixCommandId?}`。诊断规则只在对应节点修改后调度重检查；对未知自定义语法不默认产生会破坏文件的自动修复。诊断面板为 P1 按需功能。

## 12. DDS-11 PLUGIN 注册器与Worker（FR-035~039/041）

### 12.1 Manifest Schema

参见 [plugin_manifest.schema.json](contracts/plugin_manifest.schema.json) 及 [示例清单](contracts/plugin_manifest.example.json)。Manifest必须包含 `pluginId`, `version`, `apiVersion`, `activation`, `permissions`, `contributions`；重复命令ID被拒绝。

### 12.2 安装状态机

`Discovered → Validated → Registered(metadata only) → PermissionCheck → LoadingWorker → Running → Idle → Unloaded`。

- 安装时校验JSON Schema、API版本、ID命名空间、来源/散列、路径规范。
- 注册工具时**不加载插件代码**；只有点击工具时才加载Worker。
- P0至少能禁用/卸载执行体与工具注册；更新失败回滚已知可用Manifest。
- 高风险权限/外部进程执行由 PermissionHost + OS安全边界共同强制执行，不可信DLL不得直接加载在宿主进程中。
- Worker崩溃、超时、传输错误时失败关闭，CommandBus不应用任何补丁。

### 12.3 安全分级

| 级别 | 插件类别 | 允许能力 | 限制 |
|---|---|---|---|
| L0 | 内置命令，仅元数据 | 源文本范围编辑 | 不加载外部代码 |
| L1 | 声明式模板/命令 | 通过CommandBus的受控事务 | 不允许任意网络、进程 |
| L2 | 第三方代码Worker | 明确授予的最小文件/网络能力 | 必须OS隔离或不允许运行 |
| L3 | 用户显式可信原生插件 | 宿主明确接受风险后启用 | 不宣称隔离安全等价 |

更多协议见：[命令与Worker契约](contracts/command_and_worker_contract.md)。

## 13. DDS-12 SECURITY 授权与输入安全（FR-040）

`PermissionHost` 策略输入：插件身份、工作区、操作、目标URI、用户授予范围；输出 `ALLOW/DENY/PROMPT`，决策在每次敏感调用重检。插件不能直接绕过宿主写入磁盘；如果运行机制无法做到强隔离，需关闭高风险扩展并记录未满足条件。

本地预览以隔离Origin运行，阻断未授权导航/远程请求/脚本。任何外部AI上下文发送前向用户明确显示范围与目的地。

## 14. DDS-13 AI 提案审查（FR-042~044）

1. 依据`allowedRanges`选取最小上下文，追加必要且已授权的引用，所有片段携带`uri + version + range`。
2. 由AI适配器返回 `PatchProposal(expectedVersion, allowedRanges, edits)`；拒绝直接文件写入。
3. 先比对版本与范围，形成只读差异视图；用户拒绝则不产生Host EditTransaction。
4. 接受时再次比对版本/授权并通过CommandBus原子提交；保存动作单独受宿主策略控制。
5. AI输出包含恶意HTML、路径越权等内容时仍按预览/编码/写权限检查。

## 15. DDS-14 GIT / DDS-15 TRACE（FR-045~048）

### 15.1 Git

Git适配器只读取当前`workspaceId`对应工作树和目标Git状态；同名文件通过工作树根与规范化URI区分。默认使用宿主已有Git能力；无仓库/无Git时静默不启用此功能但可提示原因。

### 15.2 追踪sidecar

P1可选`markdown-trace.json`侧写关系，结构为`{schemaVersion,workspaceId,edges:[{fromReqId,toUri,toSymbolOrAnchor,kind}]}`。更新前校验target存在，缺失保留broken状态，不自行删除需求。P2关系图只是sidecar视图，不强制数据库服务。

### 15.3 工作流

策略引擎输入`ChangeSet,TraceEdges,DocumentVersion,ProjectPolicy`，输出`PASS/WARN/BLOCK`与规则ID。例外审批必须附原因、时间、批准方，不能把未检内容伪称通过。

## 16. DDS-16 EXPORT / DDS-17 OPTIONAL（FR-028/047/049）

Markdown模板为可修改纯文本，首期不得把模板系统变成必需服务。HTML导出可使用现有安全预览HTML处理链；PDF/DOCX作为独立按需导出适配。WYSIWYG与节点图分别为P2插件，不影响P0发布和非MD文件性能。

## 17. 并发、任务取消与资源预算

- `RenderJob={sessionId,version,cancellationToken,priority}`。用户按键优先级高于解析/图表；同session过期版本不得更新UI。
- 禁止在UI线程进行完整GFM解析、Mermaid运行、网络请求或图片解码大对象。
- 预览视图关闭时取消排队任务，释放渲染上下文与独占句柄。
- 空闲Worker由插件生命周期策略回收；为避免冷热抖动可保留短时缓存，但必须满足NFR-003/NFR-009验收。
- 文件超过阈值时提示并降级，阈值属于配置/POC，不将10MiB强行解释为失效边界。

## 18. 详细错误码与事务保障

| 内部错误 | 触发检查点 | 返回策略 | 副作用 |
|---|---|---|---|
| CONFLICT | expectedVersion mismatch | 用户重新审查 | 无 |
| INVALID_RANGE | offset/Unicode边界无效 | 拒绝并记录源位置 | 无 |
| IME_ACTIVE | 正在输入法组合 | 结束组合后重试 | 无 |
| READ_ONLY | 宿主只读状态 | 提示不可写 | 无 |
| FILE_RACE | 磁盘指纹已变化 | 交给宿主冲突UI | 无自动覆盖 |
| ENCODING_LOSS | 目标编码不可表示 | 弹出编码选项 | 不写磁盘 |
| PERMISSION | URI/插件权限不足 | 拒绝并诊断 | 无 |
| PLUGIN_CRASH | worker异常退出 | 隔离并注销任务 | 无未确认编辑 |
| PLUGIN_TIMEOUT | 调用超过策略上限 | 取消worker请求 | 无 |
| PREVIEW_UNAVAILABLE | 渲染组件缺失 | 回退源码 | 不修改正文 |

## 19. 最低实现清单 / 代码审查准则
