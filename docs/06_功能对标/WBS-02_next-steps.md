# [WBS-02] 与 Sakura 的剩余差距与下一步开发计划

> 基线: v0.1.2 (2026-10-27)。本文件取代 WBS-01 / SPA-03 附录 A 里已经过时的"缺失"标注(那两份写于 10-18/19, 之后很多项已实现)。
> 方法: 6 个区域各派一位审计员读**当前代码和测试**, 每条缺口都带证据; 读不出结论的标"待验证"。差距里"有测试覆盖"仅指 `tests/mock` 的"268 条命令可达且有可见变化"和 `tests/sakura-diff` 的 237 条与真实 Sakura 的行为比对(236 条一致)。

## 1. 现状一句话

编辑核心(移动/选择/删除/剪贴板/矩形/撤销/词模型/查找替换)已经按真实 Sakura 逐条比对, 268 条命令都"可达"。**差距主要在核心之外**: 文件入口与数据安全、设置体系、Grep 深度、宏与插件、外观与互操作、超大文件。

## 2. 比 Sakura 少的功能(按影响排序的前 10 项)

| # | 缺的功能 | 为什么重要 |
|---|---|---|
| 1 | **原生"打开 / 另存为"对话框, 项目根之外的路径, 打开到指定行(`path:行:列`)** | 现在靠 `prompt()` 输入项目内相对路径, Save As 只问文件名; 拖入打开、最近文件、命令行、标签跳转都被它卡住 |
| 2 | **真正的 Sakura 宏语言**: `S_*` 命令解释器、按命令记录的键盘宏、`.mac` 文本读写 | 现在是私有的 `.mac.json`(KeyboardEvent 回放, 60 ms 一步); 现成的 Sakura `.mac` 文件不能用, 键位一改回放就坏 |
| 3 | **タイプ別設定**(类型别设置)可编辑对话框, 且每项真正生效、可持久化、可自定义类型 | Sakura 的核心配置概念; 现在 Ctrl+4/5 只是只读的关键字计数列表, `TypeConfig` 没有 Tab 宽/缩进/颜色/大纲/折行字段 |
| 4 | **共通設定**各页 + OK/取消 + 可携带的设置文件 + `sakura.ini` 导入 | 18 页里只有约 3 页有对应, 改动立即生效没有取消; 设置存在 WebView localStorage, 不可携带也不可手改 |
| 5 | **文件安全**: 外部改动检测、关窗口未保存提示、原子保存、保存时备份 | 现在可能静默覆盖别的程序的改动; 保存是原地 `fs::write`; 自动备份是手动命令且不管文档编码 |
| 6 | **Grep 深度**: Grep 置換真的改文件、按文件编码检索、输出选项、已打开缓冲区范围、统一正则引擎 | Grep 置換是个不执行的对话框; Grep 用 `from_utf8_lossy` 解码, SJIS/EUC 树会乱码或漏命中; Grep 的 MiniRegex 与查找的 `regex` 不一致, 都不支持环视和反向引用 |
| 7 | **外部命令捕获输出 + 文本过滤** | Ctrl+F5 只是把命令打进终端; 没有输出窗口、没有把选区当 stdin、没有"把输出插入文档" |
| 8 | **JS 宏 `Editor.*` API、可用的 wasm 插件 ABI、`plugin.def`** | wasm 插件加载函数返回字面量 `"WASM result"`, 插件做不了任何文本变换; JS 宏只有 5 个成员 |
| 9 | **文件/文本拖放、剪贴板对矩形与行模式的互操作** | 没有任何 drop 处理; 在 Sakura / Visual Studio 之间复制矩形或整行会变成普通文本 |
| 10 | **超大文件与折行/宽度模型**: 4 MB 上限、折行感知的光标移动、按 N 列折行、CJK/代理对宽度、自由光标 | 读取上限 4 MB, 前端按整份行数组渲染; "折行到 N 列"目前是 CSS `max-width` 近似 |

已核对属实: 没有关窗口提示的处理代码(`beforeunload` / `close-requested` 均无)、wasm 加载是桩、Grep 用 `from_utf8_lossy`。

## 3. 不适用 / 以等价物代替(不列入开发)

SQL\*Plus 会话集成(Oracle/Win32 专用, 保留悬浮终端为等价)· VBScript 等 WSH 宏(由 JS 宏 API 代替)· MDI/SDI 窗口命令(层叠/平铺/窗口列表, 本应用是单窗口多标签, 记为有意偏差)· 基于 OS 共享标志的独占控制(现 `.lock` 旁路文件挡不住别的程序, 可后续改 Windows 共享模式, 否则记为等价)· `sakura.chm` 帮助(内置帮助为等价)· TSF 再変換(WebView 里无法触发, 现有辅助为可接受等价)· 印刷版面引擎(`window.print()` 为等价, 分页不会一致, 只做视觉 UAT)· `.lnk`/UNC/长路径边角(仅 Tauri `fileAssociations` 值得做)· 带汉字词典的 Migemo(罗马字→假名候选已够)。
