**U-04 は 2026-10-18 に解決した。** 純 Rust 化が決定され、
全 WBS の実装先が Rust (`ide-kernel` / `editcore`) に固定された。

**影響:** 工期表 (§1) は変更なし。変わるのは「どこで書くか」だけ (JS → Rust)。
ただし [ARCH-01](ARCH-01_pure-rust-migration.md) の Phase 1 (JS↔Rust 橋 +
130 command の Rust 化) が **新規工程 8-12 人日** として追加された。
総合工数: **37-48 → 45-60 人日**。

**2026-10-18 追記:** Web 版維持方針が確定 (同 ADR §5.1) したため、橋は HTTP 拡張に
決まり、Phase 1 は **8-12 人日で確定** (Web 版を捨てれば 4 人日に縮む選択肢は消えた)。
残りの不確実性は U-01 (PPA 互換性) と U-02 (プラグイン ABI) の 2 件のみ。
