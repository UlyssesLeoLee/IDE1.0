## 1. セキュリティ脅威分析

### 1.1 脅威シナリオ

#### [THREAT-001] Plugin Code Injection
**脅威**: 悪意あるコードが Plugin として導入される
**影響**: Workspace 全体へのアクセス、ファイル盗難
**対策**: 
- Plugin Manifest による Permission 宣言
- Zero Trust モデル（デフォルト Deny）
- Plugin コード署名【TBD】
- Sandboxing（WASM）

#### [THREAT-002] Agent による過度なアクセス
**脅威**: Agent が与えられた Permission を超えてアクセス
**影響**: 機密ファイル読み取り、意図しない削除
**対策**:
- Permission チェック（すべての Kernel API）
- Session スコープの Permission
- Audit ログで Agent 動作追跡

#### [THREAT-003] Workspace 外ファイル操作
**脅威**: symlink/hard link を通じた Workspace 外アクセス
**影響**: 他プロジェクトのファイル盗難
**対策**:
- Path canonical 化（symlink 解決）
- allowed_paths/blocked_paths 検証
- ファイルアクセス前の権限チェック

#### [THREAT-004] Network 通信盗聴
**脅威**: Remote AI/Cloud service への通信盗聴
**影響**: Code context, Secret leak
**対策**:
- TLS 1.3 強制
- Certificate pinning（Remote service）
- Network Permission 段階化

#### [THREAT-005] Secret 盗難
**脅威**: Environment Variable から Secret 窃取
**影響**: OAuth token, API key 漏洩
**対策**:
- Secret API（Environment Variable 直接アクセス禁止）
- OS Secret Store（Keyring/Keychain/DPAPI）
- Secret Rotation（将来）

#### [THREAT-006] Process Escaping
**脅威**: Plugin が子プロセスを通じて任意コード実行
**影響**: ローカルマシン制御喪失
**対策**:
- process.spawn デフォルト禁止
- Executable allowlist
- Environment variable filter
- Process timeout

#### [THREAT-007] Crash による情報漏洩
**脅威**: Plugin/Worker Crash 時のメモリダンプから Secret 流出
**影響**: Context, Secret 漏洩
**対策**:
- Plugin は隔離 Worker（native dylib ではない）
- Crash dump 暗号化【TBD】
- Coredump disable

#### [THREAT-008] Transaction Rollback 後のデータ復帰
**脅威**: Rollback 後にクラッシュ、復帰ジャーナル読み取り
**影響**: 機密データ露出
**対策**:
- Journal ファイル暗号化
- File permission (mode 0600)
- Secure delete（overwrite）

## 2. 認証・認可設計

### 2.1 認証モデル

#### Session-based Authentication

```
┌─────────────────────────────────────────┐
│ Agent/CLI/TUI                           │
└────────────┬────────────────────────────┘
             │
    1. Session.create
       (actor=langgraph, permissions={...})
             │
┌────────────▼────────────────────────────┐
│ Kernel Session Manager                  │
└────────────┬────────────────────────────┘
             │
    2. Generate session_id + expiry_token
             │
┌────────────▼────────────────────────────┐
│ Client: Store session_id                │
└─────────────────────────────────────────┘

3. 以後の Request に session_id を含める
```

**Session 属性**:
- session_id: UUID
- actor: Human | LangGraph | Agent | CI | Plugin | Automation
- workspace_id: 作業対象ワークスペース
- permissions: PermissionSet
- resource_budget: CPU/Memory/Tokens
- created_at: Timestamp
- expires_at: Timestamp
- last_activity: Timestamp

**Session TTL**:
- Default: 8 hours（Human）
- Agent: 24 hours【TBD】
- Idle timeout: 30 minutes（inactivity）

#### HTTP Authentication

**Bearer Token**（Agent API）:
```
Authorization: Bearer <session_token>
```

**mTLS**（Remote Kernel）:
```
Client Certificate で認証
```

### 2.3 Permission チェック実装

**エントリポイント**: すべての Command 実行前

```rust
pub async fn check_permission(
    session: &Session,
    command: &Command,
) -> Result<()> {
    match command.name.as_str() {
        "file.read" => {
            require_permission!(session, filesystem_read)?;
            let path = &command.arguments["path"];
            check_workspace_path_read(path)?;
        }
        "file.patch" => {
            require_permission!(session, filesystem_write)?;
            let path = &command.arguments["path"];
            check_workspace_path_write(path)?;
        }
        "process.spawn" => {
            require_permission!(session, process_spawn)?;
            let exe = &command.arguments["executable"];
            check_executable_allowlist(exe)?;
        }
        "ai.complete" => {
            if command.arguments.get("remote") == Some("true") {
                require_permission!(session, ai_remote)?;
            } else {
                require_permission!(session, ai_local)?;
            }
        }
        _ => {}
    }
    Ok(())
}
```

## 3. Workspace セキュリティ

### 3.1 Path-based Access Control

**実装**:
```rust
pub struct PathPolicy {
    pub workspace_id: WorkspaceId,
    pub allowed_paths: Vec<PathPattern>,    // ["/src/auth*", "/tests*"]
    pub read_only_paths: Vec<PathPattern>,  // ["/config*"]
    pub write_paths: Vec<PathPattern>,      // ["/src/", "/tests/"]
    pub blocked_paths: Vec<PathPattern>,    // ["/secrets", "/config/prod.toml"]
}

pub async fn check_path_access(
    session: &Session,
    path: &Path,
    operation: FileOperation, // Read, Write, Delete
) -> Result<()> {
    let canonical_path = path.canonicalize()?;  // Symlink 解決
    
    // 1. Blocked paths チェック
    for pattern in &session.path_policy.blocked_paths {
        if matches_pattern(&canonical_path, pattern) {
            return Err(PathBlocked);
        }
    }
    
    // 2. Allowed paths チェック
    let allowed = session.path_policy.allowed_paths.iter()
        .any(|p| matches_pattern(&canonical_path, p));
    if !allowed {
        return Err(PathNotAllowed);
    }
    
    // 3. Operation-specific チェック
    match operation {
        FileOperation::Read => {
            // 既に allowed paths で許可されている
        }
        FileOperation::Write | FileOperation::Delete => {
            // Read-only paths チェック
            for pattern in &session.path_policy.read_only_paths {
                if matches_pattern(&canonical_path, pattern) {
                    return Err(PathReadOnly);
                }
            }
            // Write permission チェック
            require_permission!(session, workspace_write)?;
        }
    }
    
    Ok(())
}
```

**デフォルトポリシー**:
- Reviewer Agent: allowed_paths = [workspace_root]
- Coder Agent: allowed_paths = [workspace_root], write_paths = ["/src/"]

### 3.2 Workspace Sandbox Escape 対策

**対策 1: Canonical Path**
```rust
// ❌ 危険
if path.starts_with("/allowed/") { allow_access(); }

// ✓ 安全
let canonical = path.canonicalize()?;  // symlink を resolve
if canonical.starts_with(workspace_root.canonicalize()?) { allow_access(); }
```

**対策 2: Hard link 対策**
```rust
// ファイルアクセス前に inode を確認
let stat_before = std::fs::metadata(path)?;
let content = std::fs::read(path)?;
let stat_after = std::fs::metadata(path)?;
if stat_before.ino() != stat_after.ino() {
    return Err(FileModified); // TOCTOU 攻撃検出
}
```

## 4. Process Execution セキュリティ

### 4.1 Process Spawn 制御

**デフォルト**: Deny

```rust
pub struct ProcessSpawnPolicy {
    pub enabled: bool,
    pub executable_allowlist: Vec<String>, // ["cargo", "rustfmt", "clippy"]
    pub working_directory: Option<PathBuf>,
    pub timeout_secs: u64,
    pub environment_filter: EnvironmentFilter,
}

pub async fn check_spawn_permission(
    session: &Session,
    executable: &str,
    args: &[String],
) -> Result<()> {
    require_permission!(session, process_spawn)?;
    
    let policy = &session.process_policy;
    if !policy.enabled {
        return Err(ProcessSpawnDisabled);
    }
    
    // Executable allowlist チェック
    let exe_name = std::path::Path::new(executable)
        .file_name()
        .unwrap()
        .to_str()
        .unwrap();
    
    if !policy.executable_allowlist.contains(&exe_name.to_string()) {
        return Err(ExecutableNotAllowed);
    }
    
    Ok(())
}

pub fn filter_environment(
    session: &Session,
    env: &HashMap<String, String>,
) -> HashMap<String, String> {
    let mut filtered = env.clone();
    
    // Secret 変数を削除
    for secret_pattern in &["SSH_*", "AWS_*", "GITHUB_*", "API_KEY*"] {
        filtered.retain(|k, _| !wildcard_match(k, secret_pattern));
    }
    
    filtered
}
```

```rust
pub async fn check_network_access(
    session: &Session,
    destination: &str, // domain or IP
) -> Result<()> {
    match &session.permissions.network {
        NetworkPermission::Deny => {
            Err(NetworkDenied)

        NetworkPermission::LanOnly => {
            if is_private_ip(destination) {
                Ok(())
            } else {
                Err(NetworkNotLocal)
            }

            for pattern in allowlist {
                if domain_matches(destination, pattern) {
                    return Ok(());
                }
            }
            Err(DomainNotAllowed)
        }
        NetworkPermission::Allow => Ok(()),
    }
}
```

```rust
pub struct SecretManager {
    store: Box<dyn SecretStore>, // OS Secret Store
}

impl SecretManager {
    pub async fn get(
        &self,
        name: &str,
        required_permission: Permission,
    ) -> Result<String> {
        // 1. Permission チェック
        let session = get_current_session();
        require_permission!(session, required_permission)?;
        
        // 2. Audit ログ記録
        audit_log(AuditEntry {
            actor: session.actor,
            operation: "secret_access",
            secret_name: name,
            timestamp: now(),
        })?;
        
        // 3. OS Secret Store から取得
        self.store.get(name).await
    }
}
```

### 7.2 Audit ログ改ざん防止

**実装**: Hash chain
```rust
pub struct AuditLogEntry {
    pub id: AuditId,
    pub timestamp: Timestamp,
    pub content: AuditContent,
    pub hash: Hash,           // current entry hash
    pub prev_hash: Hash,      // previous entry hash
}

pub async fn append_audit_log(
    &mut self,
    entry: AuditLogEntry,
) -> Result<()> {
    let last_entry = self.get_last_entry()?;
    let new_hash = sha256(&(entry.content + &last_entry.hash));
    
    let entry_with_hash = AuditLogEntry {
        hash: new_hash,
        prev_hash: last_entry.hash,
        ..entry
    };
    
    self.store.append(&entry_with_hash).await?;
}

// 検証
pub async fn verify_log_integrity(&self) -> Result<()> {
    let mut prev_hash = GENESIS_HASH;
    
    for entry in self.store.read_all().await? {
        if entry.prev_hash != prev_hash {
            return Err(LogTampered);
        }
        let computed_hash = sha256(&(entry.content.clone() + &entry.prev_hash));
        if computed_hash != entry.hash {
            return Err(LogCorrupted);
        }
        prev_hash = entry.hash;
    }
    
    Ok(())
}
```

### 8.2 Rate Limiting

```rust
pub struct RateLimiter {
    buckets: Arc<RwLock<HashMap<SessionId, TokenBucket>>>,
}

pub async fn check_rate_limit(
    &self,
    session_id: &SessionId,
    quota: u32,
) -> Result<()> {
    let mut buckets = self.buckets.write().await;
    let bucket = buckets.entry(session_id.clone())
        .or_insert_with(|| TokenBucket::new(quota));
    
    if bucket.try_consume(1) {
        Ok(())
    } else {
        Err(RateLimitExceeded)
    }
}
```
