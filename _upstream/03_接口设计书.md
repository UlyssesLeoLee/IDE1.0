## 1. 接口体系概述

本文档定义 Kernel 对外暴露的所有接口，分为以下 5 层：

```
┌─────────────────────────────────┐
│    Human / Agent / CI CLI       │
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│     Protocol Layer (Transport)  │
│  REST / JSON-RPC / MCP / A2A    │
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│    Unified API Layer            │
│ Command / Event / Capability    │
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│       Microkernel               │
│ Bus / Registry / Manager        │
└─────────────────────────────────┘
```

每个接口使用唯一 IF ID，明确：
- Source（调用者）
- Destination（被调用者）
- Direction（方向）
- Protocol（协议）
- Endpoint/Topic（端点）
- Method（方法）
- Encoding（编码）
- Schema（数据结构）
- Authentication（认证）
- Authorization（授权）
- Request（请求）
- Response（响应）
- Error Handling（错误处理）
- Timeout（超时）
- Retry Policy（重试）
- Idempotency（幂等性）
- Ordering（顺序性）
- Version Compatibility（版本兼容）
- Monitoring（监控）

## 2. 统一 API 层接口（Unified API Layer）

### 2.1 Command API

#### [IF-CMD-001] Command Execution

**接口 ID**: IF-CMD-001
**Source**: TUI / Agent / CLI / Plugin
**Destination**: Kernel Core (Command Bus)
**Direction**: Request-Reply
**Protocol**: Rust in-process / JSON-RPC / HTTP

**请求结构**:
```json
{
  "command_id": "uuid",
  "name": "file.read",
  "version": "1.0",
  "session_id": "session-123",
  "actor": "human|langgraph|agent|ci|plugin|automation",
  "permissions": {...},
  "arguments": {
    "path": "/src/main.rs",
    "encoding": "utf-8"
  },
  "timeout_ms": 30000,
  "metadata": {...},
  "cancellation_token": "..."
}
```

**响应结构**:
```json
{
  "command_id": "uuid",
  "status": "ok|error|cancelled",
  "data": {
    "content": "...",
    "size_bytes": 1234,
    "encoding": "utf-8",
    "version": 1
  },
  "diagnostics": [...],
  "metadata": {...},
  "side_effects": [
    {
      "type": "BUFFER_OPENED",
      "document_id": "doc-456"
    }
  ],
  "next_cursor": null
}
```

**错误格式**:
```json
{
  "command_id": "uuid",
  "status": "error",
  "error": {
    "code": "PERMISSION_DENIED|FILE_NOT_FOUND|VERSION_CONFLICT|TIMEOUT",
    "message": "...",
    "retryable": true|false,
    "details": {...}
  }
}
```

**认证/授权**:
- Session 中包含 actor 及其 permissions
- Command 执行前检验 permissions

**超时**:
- 默认: 30 秒
- 可在 Request 中覆盖
- Timeout 后返回 timeout error，Worker 继续清理

**重试**:
- Idempotent command（read-only）: 自动重试 3 次
- Non-idempotent command: 需显式 retry parameter

**幂等性**:
- file.read: 幂等
- file.patch: 非幂等（需 version/hash 验证）
- test.run: 非幂等

**监控**:
- 每个 Command 执行记录到 Audit Log
- 性能指标（执行时间）到 Prometheus

**版本**:
- Kernel API 版本: v1（Manifest 中声明）
- 后向兼容性保证【TBD】

### 2.2 Event API

#### [IF-EVT-001] Event Stream

**接口 ID**: IF-EVT-001
**Source**: Kernel Core (Event Bus)
**Destination**: TUI / Agent / Monitoring System
**Direction**: Server-to-Client (streaming)
**Protocol**: SSE / WebSocket / stdio (json-lines)

**事件格式**:
```json
{
  "event_id": "uuid",
  "sequence": 12345,
  "type": "CommandStarted|CommandCompleted|BufferChanged|FileSaved",
  "timestamp": "2026-09-14T10:00:00Z",
  "workspace_id": "ws-123",
  "session_id": "session-456",
  "execution_id": "exec-789",
  "actor": "langgraph",
  "payload": {
    "command_id": "cmd-001",
    "command_name": "file.read",
    "path": "/src/main.rs"
  }
}
```

**事件分类**:
- **Transient**: CursorMoved, KeyPressed（不持久化）
- **Durable**: TransactionCommitted, FileSaved（持久化）

**订阅过滤**:
```
/v1/events/subscribe?type=CommandCompleted&session_id=session-456
```

**连接保活**:
- Heartbeat: 每 30 秒一个 keepalive event
- Timeout: 60 秒无数据断开连接

### 2.3 Capability API

#### [IF-CAP-001] Capability Registration

**接口 ID**: IF-CAP-001
**Source**: Plugin
**Destination**: Kernel Core (Capability Registry)
**Direction**: Request-Reply
**Protocol**: Rust in-process

**请求**:
```rust
registry.register_capability(
  Capability {
    id: "language.definition",
    version: "1.0",
    provider: Box::new(RustAnalyzerPlugin),
    permissions: vec!["workspace.read"],
    priority: 100,
    availability: Available,
  }
)?;
```

**响应**:
```
Ok(capability_id)
```

**冲突处理**: 同名 Capability 后者覆盖前者

---

#### [IF-CAP-002] Capability Routing

**接口 ID**: IF-CAP-002
**Source**: Kernel Core (Command Bus)
**Destination**: Capability Registry → Plugin
**Direction**: Request-Reply
**Protocol**: Rust in-process

**内部流程**:
```
1. Command 来到 Command Bus
2. Bus 查询 Capability Registry
3. Registry 根据 Priority/Policy/Availability 选择 Provider
4. Bus 调用 Provider
5. Provider 返回结果
```

**选择标准**:
- Capability 名称匹配
- Priority 最高
- Availability 检查（ACTIVE 状态）
- Permission 检查（Provider 需要的 Permission）
- Resource 检查（CPU/RAM budget）

**示例**:
```
ai.embed 的 Provider 候选:
  - LocalEmbedder (priority=100, available)
  - RemoteEmbedder (priority=50, remote_ai_disabled)
→ 选择 LocalEmbedder
```

## 6. 错误处理

### 标准错误码

| Code | HTTP | 描述 | Retryable |
|------|------|------|-----------|
| OK | 200 | 成功 | N/A |
| INVALID_ARGUMENT | 400 | 参数无效 | No |
| PERMISSION_DENIED | 403 | 权限不足 | No |
| NOT_FOUND | 404 | 资源不存在 | No |
| CONFLICT | 409 | 版本/状态冲突 | Yes |
| RESOURCE_EXHAUSTED | 429 | 资源耗尽 | Yes |
| TIMEOUT | 504 | 操作超时 | Yes |
| INTERNAL | 500 | 内部错误 | Yes |
| UNAVAILABLE | 503 | 服务不可用 | Yes |

## 7. 接口版本管理

### 版本策略
- **Kernel API Version**: v1（major version in URL）
- **Plugin API Version**: 在 Manifest 中声明
- **Backward Compatibility**: Major version 内保证兼容

### Deprecation Process
1. 新版本发布时标记为 Deprecated
2. 至少保留 2 个主版本期间可用
3. Release notes 中明确告知
4. 日志中输出 deprecation warning

---

## 8. 接口安全性

### 认证
- **Session-based**: TUI/内部调用
- **Token-based**: HTTP API (Bearer Token)
- **mTLS**: 可选，用于远程通信

### 授权
- **Permission-based**: 每个 Command 检查 Session 权限
- **Capability-based**: Plugin 依赖 Capability 而非直接调用

### 加密
- **TLS 1.3**: 所有 HTTP 通信
- **Secret Encryption**: OS Secret Store
