### 2.2 Command Bus 設計

**責任**:
- Command 受け取り
- Permission 検証
- Capability ルーティング
- Plugin 呼び出し
- 結果返却
- Event 発行

**実装概要**:
```rust
pub struct CommandBus {
    capability_registry: Arc<CapabilityRegistry>,
    session_manager: Arc<SessionManager>,
    event_bus: Arc<EventBus>,
    command_id_generator: AtomicU64,
}

impl CommandBus {
    pub async fn execute(
        &self,
        command: Command,
    ) -> Result<CommandResult> {
        // 1. Command ID 生成
        let cmd_id = self.command_id_generator.next();
        
        // 2. Permission 検証
        let session = self.session_manager.get(&command.session_id)?;
        self.check_permissions(&session, &command)?;
        
        // 3. Event 発行: CommandStarted
        self.event_bus.emit(CommandStarted { command_id: cmd_id, ... })?;
        
        // 4. Capability 検索
        let provider = self.capability_registry.route(&command.name)?;
        
        // 5. Provider 呼び出し
        let result = provider.execute(command).await?;
        
        // 6. Event 発行: CommandCompleted
        self.event_bus.emit(CommandCompleted { command_id: cmd_id, ... })?;
        
        Ok(result)
    }
}
```

### 2.3 Event Bus 設計

**責任**:
- Event 受け取り・保存
- 購読者への配信
- Event Stream (SSE/WebSocket)
- Durability (Journal)

**実装概要**:
```rust
pub struct EventBus {
    event_store: Arc<EventStore>,
    subscribers: Arc<RwLock<HashMap<SubscriptionId, Subscriber>>>,
}

impl EventBus {
    pub async fn emit(&self, event: Event) -> Result<()> {
        // 1. Event ID + Sequence 割り当て
        let event = event.with_id(generate_id()).with_seq(self.next_seq);
        
        // 2. Durable event は journal に書き込み
        if event.is_durable() {
            self.event_store.append(&event).await?;
        }
        
        // 3. 購読者に配信
        for subscriber in self.subscribers.read().await.values() {
            subscriber.send(event.clone()).await?;
        }
        
        Ok(())
    }
}
```

### 2.4 Capability Registry 設計

**責任**:
- Plugin による Capability 登録
- Capability クエリ
- Provider ルーティング
- Priority/Policy 管理

**実装概要**:
```rust
pub struct CapabilityRegistry {
    capabilities: RwLock<HashMap<String, Vec<Provider>>>,
}

impl CapabilityRegistry {
    pub fn register(
        &self,
        capability: CapabilityName,
        provider: Box<dyn CommandProvider>,
    ) -> Result<()> {
        let mut caps = self.capabilities.write();
        caps.entry(capability.to_string())
            .or_insert_with(Vec::new)
            .push(Provider {
                id: generate_id(),
                impl_box: provider,
                priority: DEFAULT_PRIORITY,
                availability: Available,
            });
        // Priority でソート
        caps[&capability.to_string()].sort_by_key(|p| std::cmp::Reverse(p.priority));
        Ok(())
    }

    pub async fn route(
        &self,
        capability: &str,
        session: &Session,
    ) -> Result<Arc<dyn CommandProvider>> {
        let caps = self.capabilities.read();
        let providers = caps.get(capability)?;
        
        for provider in providers {
            // Permission チェック
            if session.check_permissions(&provider.required_permissions()).is_ok()
                && provider.is_available().await
            {
                return Ok(provider.impl_box.clone());
            }
        }
        
        Err(CapabilityNotAvailable)
    }
}
```

### 2.6 Transaction Manager 設計

**責任**:
- Transaction ライフサイクル
- Patch の記録
- Commit/Rollback
- Crash Recovery

**実装概要**:
```rust
pub struct TransactionManager {
    transactions: Arc<RwLock<HashMap<TransactionId, Transaction>>>,
    journal: Arc<Journal>,
}

pub struct Transaction {
    pub transaction_id: TransactionId,
    pub session_id: SessionId,
    pub status: TransactionStatus, // NEW → ACTIVE → VALIDATING → COMMITTED
    pub changes: Vec<FileChange>,
    pub created_at: Instant,
}

impl TransactionManager {
    pub async fn begin(
        &self,
        session_id: SessionId,
    ) -> Result<TransactionId> {
        let txn = Transaction {
            transaction_id: generate_id(),
            session_id,
            status: TransactionStatus::Active,
            changes: vec![],
            created_at: Instant::now(),
        };
        
        let txn_id = txn.transaction_id.clone();
        self.transactions.write().await.insert(txn_id.clone(), txn);
        
        // Journal に記録（Recovery 用）
        self.journal.append(&JournalEntry::TransactionBegin {
            transaction_id: txn_id.clone(),
        }).await?;
        
        Ok(txn_id)
    }

    pub async fn apply_patch(
        &self,
        transaction_id: &TransactionId,
        patch: FilePatch,
    ) -> Result<()> {
        let mut txns = self.transactions.write().await;
        let txn = txns.get_mut(transaction_id)?;
        
        // Version/Hash 検証（競合検出）
        if patch.before_hash != file_hash(patch.path) {
            return Err(VersionConflict);
        }
        
        txn.changes.push(FileChange {
            path: patch.path,
            operation: FileOperation::Patch(patch),
        });
        
        Ok(())
    }

    pub async fn commit(
        &self,
        transaction_id: &TransactionId,
    ) -> Result<()> {
        let mut txns = self.transactions.write().await;
        let mut txn = txns.get_mut(transaction_id)?;
        txn.status = TransactionStatus::Committing;
        
        // すべての変更をディスクに書き込み
        for change in &txn.changes {
            self.apply_change(change).await?;
        }
        
        txn.status = TransactionStatus::Committed;
        self.journal.append(&JournalEntry::TransactionCommit {
            transaction_id: transaction_id.clone(),
        }).await?;
        
        Ok(())
    }

    pub async fn rollback(
        &self,
        transaction_id: &TransactionId,
    ) -> Result<()> {
        // すべての変更を元に戻す
        // (in-memory ファイル内容から復帰)
        self.transactions.write().await.remove(transaction_id);
        Ok(())
    }
}
```

### 2.7 Buffer Engine 設計

**責任**:
- ファイル内容の管理（メモリ効率的）
- Undo/Redo
- Multiple エンコーディング対応
- 大容量ファイル対応

**実装概要**:
```rust
pub struct BufferEngine {
    buffers: Arc<RwLock<HashMap<DocumentId, Buffer>>>,
}

pub struct Buffer {
    pub document_id: DocumentId,
    pub file_path: PathBuf,
    pub encoding: Encoding,
    pub line_ending: LineEnding,
    pub content: Content, // Enum: InMemory(String) | Mmap(MemoryMappedFile) | Chunked(ChunkedStore)
    pub version: u64,
    pub undo_stack: Vec<UndoEntry>,
    pub redo_stack: Vec<RedoEntry>,
}

impl Buffer {
    pub async fn open(
        file_path: PathBuf,
        encoding: Encoding,
    ) -> Result<Self> {
        let metadata = std::fs::metadata(&file_path)?;
        let size = metadata.len();
        
        // 大容量ファイルは Memory Mapping
        let content = if size > 100_000_000 { // 100MB
            Content::Mmap(MemoryMappedFile::new(file_path.clone())?)
        } else {
            let raw = std::fs::read(&file_path)?;
            let text = decode_bytes(&raw, encoding)?;
            Content::InMemory(text)
        };
        
        Ok(Buffer {
            document_id: generate_id(),
            file_path,
            encoding,
            line_ending: detect_line_ending(&content)?,
            content,
            version: 0,
            undo_stack: vec![],
            redo_stack: vec![],
        })
    }

    pub async fn apply_patch(&mut self, patch: FilePatch) -> Result<()> {
        // 1. Undo ステック用スナップショット保存
        self.undo_stack.push(UndoEntry {
            version: self.version,
            snapshot: self.content.clone(),
        });
        
        // 2. Patch 適用
        let modified = self.apply_patch_internal(&patch)?;
        self.content = modified;
        self.version += 1;
        
        // 3. Redo スタック クリア
        self.redo_stack.clear();
        
        Ok(())
    }

    pub async fn undo(&mut self) -> Result<()> {
        if let Some(entry) = self.undo_stack.pop() {
            self.redo_stack.push(RedoEntry {
                version: self.version,
                snapshot: self.content.clone(),
            });
            self.content = entry.snapshot;
            self.version = entry.version;
            Ok(())
        } else {
            Err(NoUndoAvailable)
        }
    }

    pub async fn save(&self) -> Result<()> {
        let text = self.content.as_string()?;
        let bytes = encode_string(&text, self.encoding)?;
        std::fs::write(&self.file_path, bytes)?;
        Ok(())
    }
}
```

### 2.8 Plugin Manager 設計

**責任**:
- Plugin ディスカバリー・ロード
- ライフサイクル管理
- Crash 隔離
- Hot reload/unload

**実装概要**:
```rust
pub struct PluginManager {
    plugins: Arc<RwLock<HashMap<PluginId, PluginHandle>>>,
    wasm_runtime: Arc<WasmRuntime>,
    worker_pool: Arc<WorkerPool>,
}

pub enum PluginHandle {
    Wasm(WasmPluginHandle),
    Worker(WorkerHandle),
}

pub struct WasmPluginHandle {
    pub plugin_id: PluginId,
    pub manifest: PluginManifest,
    pub instance: wasmtime::Instance,
    pub status: PluginStatus,
}

pub struct WorkerHandle {
    pub plugin_id: PluginId,
    pub manifest: PluginManifest,
    pub process: std::process::Child,
    pub status: PluginStatus,
    pub last_heartbeat: Instant,
}

impl PluginManager {
    pub async fn load(&self, plugin_path: &Path) -> Result<PluginId> {
        // 1. Manifest 読み込み
        let manifest = PluginManifest::from_file(&plugin_path.join("plugin.toml"))?;
        
        // 2. Runtime 別に処理
        let handle = match manifest.runtime.typ {
            RuntimeType::Wasm => {
                let instance = self.wasm_runtime.instantiate(&plugin_path)?;
                PluginHandle::Wasm(WasmPluginHandle {
                    plugin_id: manifest.id.clone(),
                    manifest,
                    instance,
                    status: PluginStatus::Loaded,
                })
            }
            RuntimeType::Worker => {
                let process = self.worker_pool.spawn(&manifest)?;
                PluginHandle::Worker(WorkerHandle {
                    plugin_id: manifest.id.clone(),
                    manifest,
                    process,
                    status: PluginStatus::Loaded,
                    last_heartbeat: Instant::now(),
                })
            }
        };
        
        let plugin_id = match &handle {
            PluginHandle::Wasm(h) => h.plugin_id.clone(),
            PluginHandle::Worker(h) => h.plugin_id.clone(),
        };
        
        self.plugins.write().await.insert(plugin_id.clone(), handle);
        Ok(plugin_id)
    }

    pub async fn activate(&self, plugin_id: &PluginId) -> Result<()> {
        let mut plugins = self.plugins.write().await;
        let handle = plugins.get_mut(plugin_id)?;
        
        match handle {
            PluginHandle::Wasm(h) => {
                // WASM は activate hook を呼び出し
                // ...
                h.status = PluginStatus::Active;
            }
            PluginHandle::Worker(h) => {
                // Worker に activate メッセージ送信
                // ...
                h.status = PluginStatus::Active;
            }
        }
        
        Ok(())
    }

    pub async fn unload(&self, plugin_id: &PluginId) -> Result<()> {
        let mut plugins = self.plugins.write().await;
        let handle = plugins.remove(plugin_id)?;
        
        match handle {
            PluginHandle::Wasm(mut h) => {
                h.status = PluginStatus::Unloaded;
                // instance drop で自動的に cleanup
            }
            PluginHandle::Worker(mut h) => {
                h.status = PluginStatus::Unloading;
                // graceful shutdown
                h.process.kill()?;
                h.status = PluginStatus::Unloaded;
            }
        }
        
        Ok(())
    }

    pub async fn monitor_health(&self) -> Result<()> {
        let mut plugins = self.plugins.write().await;
        for (plugin_id, handle) in plugins.iter_mut() {
            match handle {
                PluginHandle::Worker(h) => {
                    // Heartbeat 確認
                    if h.last_heartbeat.elapsed() > Duration::from_secs(30) {
                        h.status = PluginStatus::Failed;
                        // 再起動ロジック
                    }
                }
                _ => {}
            }
        }
        Ok(())
    }
}
```

## 7. パフォーマンス最適化戦略

### 7.1 Startup 最適化

1. **Lazy Plugin Loading**
   - 起動時は core plugin のみロード
   - 他は on-demand

2. **Index Incremental Load**
   - 前回の index キャッシュ利用
   - 変更分のみ更新

3. **Parallel Initialization**
   - Config load, workspace detect を並列実行

### 7.2 Editing Response 最適化

1. **Priority Preemption**
   - キー入力は immediate response
   - Background tasks は低優先度

2. **Async Indexing**
   - Index 更新はバックグラウンド
   - UI をブロックしない

3. **Event Batching**
   - 高頻度 Event（CursorMove）はバッチ処理

### 7.3 Memory 最適化

1. **Memory Mapping**
   - 大容量ファイルは mmap

2. **String Interning**
   - パス・シンボル名は intern

3. **Plugin Resource Limit**
   - Plugin ごとにメモリ上限設定
