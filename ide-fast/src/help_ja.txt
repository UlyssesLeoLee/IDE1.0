IDE1.0 高速版 — 内蔵マニュアル
==============================

[1] はじめに
------------
高速版はネイティブ Rust (egui) 製の、サクラエディタ風テキストエディターです。WebView2 に依存せず、起動が速くメモリも小さく済みます。
編集 / 移動 / 検索の動作はデスクトップ版と同じコア (editcore) に由来するため、キー操作の意味はサクラエディタと一致します。
メニュー、ショートカット、コマンドパレット、ツールバー、マクロ、キー設定は同じ 1 つのコマンド表を使っています。このマニュアル末尾の「コマンド一覧」がその表です。

[2] コマンドを探す
------------------
コマンドパレット: 数文字入力するとあいまい検索でコマンドが見つかり、そのまま実行できます (コマンド一覧の「コマンドパレット」の行にキーが書いてあります)。
キー一覧: キーが割り当てられた全コマンドを表示します。
キー設定 (ヘルプメニュー): 任意のコマンドのキーを変更できます。新しいキーが他のコマンドに使われている場合は、奪うかどうか確認します。
キーワードヘルプ: ヘルプメニューの「キーワードヘルプ検索」でこのマニュアルから語を検索します。カーソルが単語上にあるときはその単語が入力済みになります。
キーワードヘルプの自動表示: オンにすると、カーソルが単語上に止まったとき、ステータスバーにその語を最初に含むマニュアルの行が表示されます。

[3] タブとウィンドウ
--------------------
1 つのウィンドウに複数のタブを開きます。ウィンドウメニューには、前 / 次のタブ、タブの移動、他 / 左 / 右を閉じる、タブグループがあります。
ウィンドウ一覧: すべてのタブを表示します (● は未保存の変更あり、▶ は現在のタブ)。文字入力で絞り込み、Enter で切り替えます。
タブグループ: タブは色でグループ分けされます。「新しいグループへ移動」「次 / 前のグループへ移動」「グループ切り替え」「グループを閉じる」があります。
ウィンドウ分割: 左右、上下、4 分割。
重ねて表示 / 並べて表示は提供しません: 単一ウィンドウ + 複数タブのアプリなので、ウィンドウ一覧とタブバーで用途を満たせます。

[4] 選択と編集
--------------
矩形選択: Alt を押しながらドラッグします。以降の入力、Backspace、Delete、コピー、切り取りは矩形全体に作用します。
範囲選択: 開始後は矢印キーで選択を拡張します。同じコマンドをもう一度実行すると終了します。
選択範囲の変換: 大文字小文字、全角半角、Tab と空白の相互変換、SPACE インデント、並べ替え、重複削除、行頭行末の空白削除。
コード変換: 選択範囲を SJIS / EUC / JIS / UTF-7 / UTF-8 / Unicode の間で変換します。
挿入: 日付、時刻、スタンプ、制御文字、最近使ったファイルのパス、最近使ったフォルダーのパス。

[5] 検索、置換、Grep
--------------------
検索バー: 大文字小文字の区別、正規表現、単語単位、折り返し、すべて強調。結果は「何件中何件目」で表示されます。
インクリメンタル検索: 入力しながらヒット位置へ移動します。正規表現と Migemo も使えます。
Grep: フォルダー内を検索し、結果をジャンプ可能なタブとして開きます。
文書比較: 2 つのタブを行ごとに突き合わせ、前 / 次の差分へ移動できます。
タグジャンプ (tags): ctags が作る tags ファイルで定義へジャンプし、元に戻れます。
定義へジャンプ: このファイル内でカーソル位置の識別子の定義行を探します。
コード補完: カーソルの左にある識別子を接頭辞とし、候補はキーワード、組み込み名、ファイル内の識別子から出します。
ジャンプ履歴: 大きなジャンプの前後の位置が記録され、進む / 戻るができます。

[6] ブックマークと折りたたみ
----------------------------
ブックマーク: 設定 / 解除、前 / 次、ブックマーク一覧。
折りたたみ: インデントに従って折りたたみ / 展開します。

[7] マクロ
----------
キーボードマクロ: キー操作を記録して再生します。ファイルに保存して読み込み直せます。
Sakura マクロ (.mac): 現在の文書または .mac ファイルを実行します。記録したキーボードマクロは .mac に変換できます。
マクロ関数 (S_ で始まる) の結末は 3 通りです: 文書上でそのまま実行、アプリに渡して実行 (保存、開く、検索、分割など)、理由を示して明示的に実行しない。
マクロ全体を先に検査し、1 ステップでも実行できないものがあれば 1 ステップも実行しません。
マクロ登録: 20 個の枠があり、各枠に Sakura マクロまたは PPA スクリプトを保存してキーに割り当てられます。

[8] ファイルと文字コード
------------------------
開くときに文字コード、BOM、改行コードを自動判別します。ステータスバーの文字コードや改行コードをクリックして変更できます。
「文字コードセットを指定して開き直す」は、選んだ文字コードでこのファイルを解釈し直します。
保存はアトミックな書き込みで、表現できない文字を黙って置き換えることはありません。
自動バックアップ: 未保存の変更がある文書を定期的にバックアップフォルダーへ書き出します。今すぐバックアップすることもできます。

[9] 設定
--------
環境設定: 全般、編集、ファイル、フォント、ツールバー、マクロ などのページ。
ツールバー: 任意のコマンドの追加、並べ替え、区切り線の追加、既定への復元ができます。
キー: コマンドパレットの隣にあるキー設定ページ。
テーマと表示言語: 中文 / 日本語 / English。

[10] 移植していないもの
-----------------------
再変換 (IME): egui には TSF の再変換を呼び出す手段がありません。
JavaScript マクロ、Vim モード、SQL*Plus: 方針として実装しません。
外部ヘルプファイル (.hlp / .chm): このマニュアルで代替します。
