IDE1.0 高速版 — 内置手册
========================

[1] 简介
--------
高速版是原生 Rust (egui) 的 Sakura 风格文本编辑器: 不依赖 WebView2, 启动快、占用小。
编辑 / 移动 / 查找的行为来自和桌面版同一个内核 (editcore), 所以键位语义和 Sakura 一致。
菜单、快捷键、命令面板、工具栏、宏、键位设置看到的是同一张命令表, 本手册末尾的「命令一览」就是这张表。

[2] 找到一个命令
----------------
命令面板: 输入几个字母就能模糊找到命令并执行 (命令一览里的「命令面板」一行写着它的键)。
键位一览: 列出每个有键的命令。
键位设置 (帮助菜单): 给任何命令改键; 新键被别的命令占着时会问你是否抢过来。
关键字帮助: 帮助菜单里的「关键字帮助检索」在本手册里查一个词, 光标在单词上时直接带入这个词。
关键字帮助自动显示: 打开后光标停在单词上, 状态栏的提示里显示手册里第一处提到它的行。

[3] 标签与窗口
--------------
一个窗口里开多个标签。窗口菜单里有: 上一个 / 下一个标签、移动标签、关闭其他 / 左侧 / 右侧、标签分组。
窗口一览: 列出全部标签 (● 表示有未保存的修改, ▶ 表示当前标签), 输入文字过滤, 回车切过去。
标签分组: 标签按颜色分组; 「移到新分组」「移到下一个 / 上一个分组」「切换分组」「关闭分组」。
拆分窗口: 左右、上下、四分割。
不做层叠、平铺: 这是单窗口多标签的应用, 窗口一览和标签栏已经覆盖了这些用途。

[4] 选择与编辑
--------------
矩形选择: 按住 Alt 拖动; 之后键入、退格、删除、复制、剪切都作用在整个矩形上。
范围选择: 开始后方向键直接扩选, 再用一次同一个命令结束。
选区变换: 大小写、全角半角、Tab 与空格互转、SPACE 缩进、排序、去重、去行首行尾空白。
代码转换: 对选区做 SJIS / EUC / JIS / UTF-7 / UTF-8 / Unicode 之间的转换。
插入: 日期、时间、戳记、控制字符、最近的文件路径、最近的文件夹路径。

[5] 查找、替换与 Grep
---------------------
查找条: 区分大小写、正则、整词、折返、全部强调; 结果显示 第几处 / 共几处。
增量查找: 边输入边跳到命中处, 可以按正则或 Migemo。
Grep: 在文件夹里查找, 结果开成一个可跳转的标签。
文档比较: 把两个标签逐行对照, 上一处 / 下一处差异。
标签跳转 (tags): 用 ctags 生成的 tags 文件跳到定义, 再跳回来。
转到定义: 在本文件里找光标处标识符的定义行。
代码补全: 光标左边的标识符作前缀, 候选来自关键字、内建名和文件里出现过的标识符。
移动履历: 大跳转前后的位置会被记下, 可以前进后退。

[6] 书签与折叠
--------------
书签: 设置 / 清除、上一个 / 下一个、书签一览。
折叠: 按缩进折叠和展开。

[7] 宏
------
键盘宏: 录制一串按键, 回放; 可以保存到文件、再载入。
Sakura 宏 (.mac): 运行当前文档或一个 .mac 文件; 录制的键盘宏可以转成 .mac。
宏函数 (S_ 开头) 有三种结局: 直接在文档上执行、交给应用去做 (保存、打开、查找、拆分等)、明确不执行并说明原因。
整份宏会先检查一遍, 有一步跑不了就一步也不执行。
宏登记: 20 个槽, 每个槽存一段 Sakura 宏或 PPA 脚本, 可以绑键。

[8] 文件与编码
--------------
打开时自动判别编码、BOM 和换行符; 状态栏上点编码或换行符可以更改。
「以指定编码重新打开」用所选编码重新解释这个文件。
保存是原子写, 不会静默替换无法表示的字符。
自动备份: 有未保存修改的文档定期写进备份目录; 也可以立即备份。

[9] 设置
--------
首选项: 常规、编辑、文件、字体、工具栏、宏 等页。
工具栏: 可以添加任何命令、排序、加分隔线、恢复默认。
键位: 命令面板旁边的键位设置页。
主题与界面语言: 中文 / 日本語 / English。

[10] 没有移植的
---------------
再変換 (IME): egui 没有触发 TSF 再変換的接口。
JavaScript 宏、Vim 模式、SQL*Plus: 按决定不做。
外部帮助文件 (.hlp / .chm): 用本手册代替。
