# 高速版路线图 / 进度

> 2026-11-04: 现状交接见 [HANDOFF-01](../../docs/06_功能对标/HANDOFF-01_高速版交接.md), 下一步的工程优化计划见 [WBS-03](../../docs/06_功能对标/WBS-03_优化计划.md)。本文件下方「没有做」表里有若干行已过期 (已实现), 以 WBS-03 O5.1 的重新校准为准。

原则: **语义放在 `editcore` (Rust), GUI 只管画和收输入**; 一个功能如果需要网页能力 (插件的沙箱 iframe 等), 留在 Tauri 版, 不在这里重做 (Mermaid 经 `svg_lite` 与 QuickJS 插件宿主做了原生近似; AI Chat 面板已在批次 10 做进来)。

## 已完成
- **基础 (里程碑 1)**: 窗口 / 多标签 / 打开·保存·另存为 (编码·BOM·换行保持) / Sakura 光标移动与编辑 / 撤销·重做 (连续键入合并) / 剪贴板 / 查找·置换 (含正则、环视) / 行号 / 状态栏 / 深浅主题 / 字号 / 拖文件打开 / 未保存提示 / CJK 显示 / 输入法 (候选窗跟随光标, 组字内联显示)。
- **第 1 期**: 语法高亮 (editcore 的 20 种语言词法 + 配色)、设置落盘 (`%APPDATA%\IDE1.0 Fast\settings.json`)、最近文件、Tab 宽度。
- **第 2 期**: 侧栏 (文件树按需读目录 / 大纲按版本缓存 / 后台线程 Grep, 点结果跳到行)、打开文件夹。
- **第 3 期**: 书签 (`editcore::bookmark`, 随行增删移动, F2 / Shift+F2 / Ctrl+F2)、矩形选择 (Alt+拖; 键入·退格·删除·回车·复制·剪切走 `box-*` 命令)、多光标 (Ctrl+点击; `multi-*` 命令)、键盘宏录制 / 回放 (Ctrl+Shift+M / L)、Sakura `.mac` 宏 (`macro_sakura::plan` 解析, 逐步执行)。
- **第 4 期**: 终端面板 (`exec_cmd` 后台执行, 历史, 清屏; 不是 PTY)、Markdown 预览 (原生块渲染, 点块跳到源码行)、自动换行 (按真实排版: 光标 / 选区 / 点击命中都跟着折行)。
- **收尾**: 命令行 `文件:行:列`、单实例 (第二次启动把文件交给已运行的窗口)、首选项窗口。
- **补完**: 折叠 (按缩进, 行号栏 ▸ 点击 / Ctrl+Shift+[ ]; 光标进入折叠自动展开)、Grep 置换 (editcore `grep_replace`, 自动 .bak 备份, 跳过有未保存修改的已打开文件, 带确认框)、自动换行下 ↑ ↓ Home End 按显示行移动。
- **0.2.0 补完**: 终端「选区作标准输入 / 输出替换选区」、分割窗口 (Ctrl+\)、标签分组、打印 / 打印预览 (系统浏览器的打印对话框)、插件的声明式部分 (主题插件生效, zip 导入 / 删除 / 恢复内置)。
- **批次 3-8 (对标 Tauri 版)**: 命令注册表与键位 (见下)、Sakura 默认键、查找 / Grep 全套、标签与窗口命令、偏好对话框 / 三语界面 / 设置导入导出、视图开关 / 标尺 / 小地图 / 空白标记、差异比较、Git 面板、常驻终端会话、脚本插件宿主 (QuickJS)。逐项状态见 `PARITY-PLAN.md` 的状态总表。
- **批次 9**: **命令面板** (Shift+F1 / Ctrl+Shift+P, 模糊匹配全部命令和插件命令)、**键位设置** (按键捕获 / 冲突抢占 / 恢复默认, 存进 `settings.json`)、**键位一览** (Ctrl+Q, 可复制)、菜单里的快捷键提示跟着改键走; 查找条 **Migemo**; **会话恢复**; 键盘宏保存 / 载入; 选到上 / 下一段落、下一处 / 上一处改动、复制文件名 / 路径、关于窗口。
- 顺带修了 `editcore::highlight_line` 在中日文行上按字节切片 panic 的 bug (Tauri 版不走这条路径, 之前没暴露)。

## 没有做 / 有意不做 (以及为什么)
| 功能 | 原因 / 状态 |
|---|---|
| **脚本插件**: Pele (mermaid) 的 markdown.fence 接入预览 | 批次 8 已嵌 QuickJS (rquickjs), 惰性启动。PPA 宏 / 文档关系图可运行 (SVG 用 `svg_lite` 子集绘制)。Pele 的包能在 QuickJS 里渲染出 SVG, 但它的 SVG 用 CSS 变量 / 复杂样式, `svg_lite` 画不好, 预览里的 fence 接入留待后续。|
| **Vim 模式、SQL*Plus** | 按决策 A8 排除: 不属于轻量文本编辑器核心, 保持原生紧凑。 |
| **IME 再変換 (reconvert, F_RECONVERT)** | egui 暂无 Windows TSF (Text Services Framework) 反向组字输入法接口。 |
| **背景亮度截屏采样** | 周期性截屏采样违反「零后台轮询 / 不拖慢」核心原则; 采用 Windows 注册表主题明暗感知替代 (`editcore::theme_luminance::detect`)。 |
| **原生文本输入键 (Ctrl+C/V/X 等) 改键** | 由底层编辑区直接吃事件, 标为系统保留键, 避免改动后与普通文本输入打架。 |
| **换行下的矩形选择 / 多光标视觉** | 矩形 / 额外光标在换行行上只画在第一个显示行。 |
| **底部面板单独 OUTPUT / PROBLEMS 页** | 目前问题整合在 Markdown 实时诊断与终端面板中, 独立多页标签视后续需求推进。 |

## 已全部实现的重点功能 (0.3.2 – 0.3.9 校准)
- **外观与导航**: 工具栏 (可自定义按钮)、功能键栏、活动栏、自绘/系统标题栏切换、应用图标、窗口一览 (Ctrl+W)。
- **编辑增强**: F6 范围选择模式、拖放选中文字 (移动/复制)、上下/左右/四分割窗格 (Panes)、光标行居中、选区字数统计切换。
- **编码与转换**: codecnv-* 全套编码转换、假名互转 (全角/半角/平假名/片假名)、插入日期/时间/戳记 (`chrono`)、base64/uudecode、copy-html、剪贴板历史。
- **安全与备份**: 自动备份定时器 (无轮询刷新)、打开时文件锁、遗留备份恢复引导、崩溃防丢。
- **导航与辅助**: tags 文件 / 目录扫描 tag jump (F12)、转到定义、关键字帮助检索、代码补全 (Ctrl+Space)。
- **宏系统全覆盖**: Sakura 宏 268 个函数各有结局 (142 个真执行、118 个转交 App、8 个明确给出原因拒绝)、宏预检拦截、宏登记槽 (20 个)。
- **发布与更新**: 自更新检查与下载校验 (ed25519 签名 + SHA256 清单绑定)、独立 MSI 安装包与便携 exe。
- **国际化**: 中 / 日 / 英三语完整支持 (菜单、提示、模板动态匹配、内置手册三份行数严格一致性测试)。

## 度量
`IDE_FAST_TRACE=1` 打印各阶段毫秒数。实测: 窗口 + GL 上下文约 170–250 ms, 首帧约 180–250 ms (冷启动 ~470 ms), 对比 Tauri 版约 1.0–1.5 s。
