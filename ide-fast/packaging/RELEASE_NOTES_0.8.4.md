# IDE1.0 v0.8.4 发行说明

### 📌 一、便笺系统全方位体验增强与缺陷修复
- **默认视口宽度加宽与工具栏完整呈现**：
  - 便笺默认视口宽度由 320px 拓宽至 440px（最小宽度限制设定为 400px）。
  - 底部 12 项富文本格式工具栏（加粗、倾斜、删除线、行内代码、代码块、超链接、待办清单、引用、分割线、表格、无序列表、有序列表）、字符/行数统计标签以及右下角缩放手柄全景展开，彻底杜绝按钮换行与显示截断。
- **删除所有便笺后持久保持用户自选便笺颜色**：
  - 便笺状态新增 `preferred_color_idx` 持久化属性。
  - 用户删除所有便笺后再新建便笺时，依然保持用户偏好的调色板纸张颜色（便签黄、薄荷绿、樱花粉、晶透蓝、炭黑等），不再重置回默认黄色。
- **彻底杜绝拖拽后窗口自我震颤/抖动**：
  - 修复了独立视口便笺窗口在拖拽移动后由于每帧重复下发 `with_position` 引起的视觉抖动缺陷。
  - 引入 `pos_initialized` 单次初始化守卫，仅在视口创建首帧定位，拖拽后平稳顺滑贴合光标。

---

### 📝 二、核心编辑器大选取复制/剪切数据完整性修复
- **彻底消除多行文本跨块复制丢失内容缺陷**：
  - 修复了 `doc.rs` 中大段选取（>8 行）在复制/剪切时误用行折叠视图端点行映射 `rows_for`，导致中间非端点行被空行覆盖的严重数据丢失问题。
  - 架构重构区分行折叠视图映射与完整编辑选取行映射 `rows_for_mode(..., full_selection)`，确保复制、剪切、删除、就地替换等原子操作始终 100% 完整无损提取所有行文本。
  - 增强 CRLF 换行规范化与 `\0` 空字符防御，跨应用程序与向便笺粘贴体验完全稳固。

---

### 🤖 三、AI Agent 运行时弹性与便笺控制工具集成
- **AI 后台请求线程 Panic 熔断守护**：
  - 在 `transport.rs` 中对网络请求与 JSON-RPC 编解码全链路注入 `std::panic::catch_unwind` 异常捕获守护。
  - 后台任务或单次请求异常时安全降级并友好报错，彻底根治工作线程意外终止导致 AI 助手假死的缺陷。
- **Agent 专属便笺控制工具全套实装**：
  - 核心 API 注册并向智能体暴露 5 项标准 Tool Call：
    - `sticky_note_list`：列出当前所有便笺、ID、颜色、标题及正文。
    - `sticky_note_create`：智能体为用户创建新便笺（支持指定颜色与 Markdown 正文）。
    - `sticky_note_update`：增量更新指定便笺的标题、内容或颜色。
    - `sticky_note_delete`：清理指定便笺。
    - `sticky_note_open`：唤起并聚焦独立便笺视口窗口。

### 🔔 五、常驻托盘退出未保存提示强制自动置顶
- 根治了从屏幕右下角托盘图标点击“退出 (Quit)”时，若存在未保存文件，确认保存弹窗被主界面遮挡、用户必须手动切换窗口才能操作的交互死锁。
- 退出事件触发时，主视口立即解除最小化、置顶聚焦 (`WindowLevel(AlwaysOnTop)`)，并在帧渲染完成后以 Windows `0x40023` (`MB_YESNOCANCEL | MB_ICONWARNING | MB_TOPMOST | MB_SETFOREGROUND`) 模态弹窗强制自动置顶显示，保障用户第一眼可见并完成保存决策。
