## IDE1.0 v0.8.0 发行说明

### 🎨 一、安装向导美漫重做与全自绘标题栏（Frameless Comic Setup Wizard）
- **彻底告别 Windows 原生标题栏与控制钮**：独立安装向导模式启用 `.with_decorations(false)` 无边框视口，基于 egui 纯自绘高饱和行动条（#FFE600）与粗黑墨线（2.0~2.5px），配备纯自绘美漫实心硬阴影最小化与关闭按钮，手感饱满，支持全区域平滑拖拽。
- **正版 Logo 严格保护**：原生解码装载用户正版 `logo-256.png` 纹理并置于爱奥尼古希腊立柱展台与左上角徽章，保留晶莹切面质感与品牌纯正度，拒绝任何非授权篡改。
- **4 步向导状态机驱动**：
  1. `Welcome`: 欢迎体验英雄展台与三大核心特性（极致响应 / 多Agent协同 / 晶透美学）；
  2. `Options`: 目标安装路径设置、全局 PATH 写入、桌面快捷方式与系统托盘驻留守护选项；
  3. `Installing`: 动态斜切速度线进度条（0%~100% 平滑推进）与美漫控制台日志（Console Dispatch Stream）；
  4. `Finished`: 部署完成状态汇总与即刻启动选项。
- **工程规范达标**：将原先超千行的安装向导重构拆分为 `installer_ui/` 模块群（`mod.rs`, `art.rs`, `steps.rs`, `tests.rs`），单文件均严格受控在 500 行预算内，图元与按键绘制全面消除重复代码。

### 🔌 二、5 大热插拔扩展模块默认内置（Hot-Pluggable Extensions）
- **随包内置，零外部依赖**：`mcp`、`hooks`、`skills`、`mod`（Claude Mod 兼容）、`automation`（代码清理与 TODO 扫描）默认随安装包内置发布，离线开箱即用。
- **运行时动态热插拔与生命周期联动**：
  - **动态启闭**：在「插件」管理面板一键开启或关闭各模块，即刻生效；
  - **热删除与一键恢复**：支持在插件页一键删除任意内置热插拔模块，删除后进入安全归档区，可随时点击“恢复内置插件”重新启用；
  - **宿主联动状态清理**：热插拔联动清理 QuickJS 运行时实例、重置 MCP 外部连接池、动态门禁 Hooks 脱敏与技能指令匹配。
- **Claude Mod 模式自由切换**：支持 `code` / `plan` / `review` / `ask` 模式动态注入系统提示词与上下文约束，并支持快捷命令循环切换。
- **强类型架构解耦**：引入强类型 `HotModuleKind` 枚举与徽章调色盘，杜绝弱类型字符串魔法值。
