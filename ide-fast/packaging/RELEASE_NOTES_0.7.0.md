## IDE1.0 v0.7.0 发行说明

### 📊 一、Markdown 渲染表格高度自适应与垂直居中
- **内容自适应行高与居中排版**：参考现代主流 Markdown 渲染引擎规范，表格各行高度根据单元格内容排版动态自适应撑大；各单元格应用动态对称填充边距 `pad_y = ((row_h - cell_h) / 2.0).max(4.0)`，完美实现 `vertical-align: middle` 上下居中对齐。
- **启发式排版常量解耦**：将字符渲染宽度启发式参数抽象为 `ASCII_CHAR_WIDTH_HEURISTIC` 与 `CJK_CHAR_WIDTH_HEURISTIC`，消除硬编码异味并支持单测严格验证。

### 🤖 二、多 Agent 并行协作体验与智能切换
- **半透明无遮挡光标圆点（Dot Marker）**：将原先覆盖在光标上方遮挡前一行代码的实体徽章胶囊，重构为半径 3.5px 的半透明小圆点（`alpha=160`，带微白光半透描边）与柔和光标竖线，彻底杜绝视线遮挡，实现多人/多Agent对同一文件的零干扰并行并发编辑。
- **对话框智能协作意图自适应切换**：在普通单智能体对话框输入多 Agent / 协同指令（如“开启多Agent协同”、“并行分工修改”等）时，系统自动识别并无缝切换至多 Agent 并行协作工作台，自动调度当前活动文件派工，彻底杜绝单智能体写入报错。
- **聊天面板与协作窗口防动态拉伸**：对 AI 对话、协同广播、流式输出、补丁提案等全部消息及代码块全面强制换行限制（`set_max_width` + `.wrap()`），且仅在用户手动拖拽调整手柄时更新面板宽度，杜绝因流式输出或长代码导致侧边栏被异常外拉。

### 🎨 三、透明主题下拉菜单文字动态反色与排版净化
- **全动态高对比度反色算法**：引入 ITU-R BT.601 感知亮度动态反色算法 `contrast_fg`，下拉菜单在实色背景下文字与勾选标记自适应反色，杜绝透明主题下下拉菜单文字看不清的问题。
- **界面冗余消除**：完全移除底部停靠栏中冗余的“协同审查”标签页，统一通过右侧全功能协同工作台与审查文档呈现，界面逻辑更清晰紧凑。
