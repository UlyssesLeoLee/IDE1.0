### 📝 一、便笺 Markdown 就地单块编辑 (In-place Block Editing) 与富文本预览无缝整合
- **所见即所得的局部就地编辑体验**：
  - 对标 IDE 原生 Markdown 模式体验，在预览模式下直接点击特定块（段落、三级标题、表格行、待办列表等）即可单独将该块切换为就地文本编辑器。
  - **其余内容 100% 保持富文本渲染不变**，彻底终结过去点击直接整篇切回原始 Markdown 纯文本代码的割裂感。
- **编辑保存与预览状态闭环**：
  - 就地微调完成后（按 Enter 或失去焦点），系统精确对正文相应行段进行无损拼接更新，便笺持续保持渲染预览模式，不会自动退回源码状态。
