## IDE1.0 v0.8.1 发行说明

### 🏛️ 一、真 3D 赛璐珞卡通渲染安装向导（True 3D Cel-Shaded Setup Wizard）
- **纯 Rust 3D 几何数学引擎**：
  - 基于纯数学实现 `Vec3`, `Mat4`, `Camera3D`，支持透视投影变换、世界-观察-投影矩阵管线、法线变换、背面剔除（Backface Culling）与画家算法（Painter's Algorithm）深度排序。
  - 零外部 3D 依赖，100% 保持轻量原生与启动零开销。
- **华丽 3D 特效套件 (Gorgeous 3D Visual Effects)**：
  - **48 颗 3D 粒子星尘涡旋 (Particle Vortex)**：以正弦螺旋轨道在空间三维环绕立柱与晶石，带有深度衰减与明暗描边。
  - **倾斜双环 3D 能量共振轨道 (Energy Aura Rings)**：双向偏转轨道光环围绕多面体旋转，动态脉冲发光。
  - **放射状旋转美漫光芒 (Radial Comic Rays)**：在 3D 背景深处以赛璐珞分色扇形旋转绽放。
  - **3D 空间八芒星光耀斑 (Diamond Starburst Glints)**：锚定在晶石与立柱金色回纹高光顶点，呼吸式绽放。
  - **超空间曲速流线 (Warp Streaks)**：Installing 部署中阶段激活 3D 纵深曲速飞掠，带来强烈的速度动量沉浸感。
  - **胜利庆典 3D 彩屑礼花 (Celebration Confetti)**：Finished 部署完成阶段漫天飞舞 3D 翻滚彩色菱形与金色彩屑。
- **全定制美漫赛璐珞控制台（彻底告别 Windows 原生 Win32 标题栏与灰色按钮）**：
  - 窗口启用无边框模式（`.with_decorations(false)`），全自绘美漫行动条标题栏与拖拽把手、美漫最小化与关闭按键。
  - 步骤卡片、路径输入框与交互卡片全面升级为赛璐珞暗夜蓝（#141A2E）配合高饱和黑墨线与机械下陷硬阴影，彻底剔除原生灰色按钮与白色表单。
- **古希腊神殿古典主义三维实体建模**：
  - **14 棱槽爱奥尼立柱台座（Ionic Fluted Pedestal）**：精准还原古希腊神殿经典的柱身收分与弧形膨胀曲线（Entasis，中部 `r_mid * 1.05`），搭配阶梯式大理石基座（Plinth）与金色回纹饰带（Meander Band）、顶部卷轴卷杀柱头（Volutes）。
  - **20 面晶钻正二十面体（20-faceted Icosahedron Gem）**：基于黄金分割比（\(\phi = \frac{1+\sqrt{5}}{2}\)）构造 12 顶点 20 晶面三维晶体，配合空间浮动与微旋转。
  - **26 片阿波罗金色桂冠（26-leaf Apollo Laurel Wreath）**：双层菱形叶脉立体环绕多面体悬浮，象征荣耀与卓越性能。
- **自由交互式 360° 拖拽观察与滚轮缩放**：
  - 支持左键拖拽自由水平旋转（Yaw）与仰俯角调节（Pitch -60°~+60°），支持滚轮无级拉近拉远（Distance 2.0~9.0）。
  - **0 静默 CPU 占用契约**：默认采用交互响应模式（`auto_rotate = false`），仅在用户鼠标交互或安装中阶段触发局部重绘，彻底消除无交互时的后台空转 CPU 消耗。
- **旗舰独立自安装程序 `IDE1.0_Setup.exe`**：
  - 自动识别 Setup 模式，内置真实物理部署能力：释放可执行文件至目标路径、创建桌面与开始菜单快捷方式、配置全局 PATH 环境变量，并在 Windows 注册表中完整登记卸载条目。

### 🔤 二、用户自装字体优先检索与首选项置顶（User Font Priority）
- **用户自装字体优先发现**：
  - 字体扫描引擎优先遍历 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`，确保用户安装的专有编程字体（如 JetBrains Mono, Fira Code, Cascadia Code, Pixel Font 等）先于系统字体被发现与加载。
  - `read_font_bytes`、`find_bold_file`、`load_ext` 均建立双重路径优先检索保障。
- **首选项外观字体下拉菜单置顶**：
  - 在「首选项 -> 外观设置 -> 字体族」下拉菜单顶部新增 **`👤 用户安装字体 (优先推荐)`** 专有置顶分组，用户安装的字体高亮展示、一目了然，一键快速应用。

### 📐 三、Alt 纵向选区恒定间距与短行自动补空格对齐（Sakura Experience Alignment）
- **100% 恒定行列间距与无抖动渲染**：
  - 彻底移除原有的行间距与列间距动态动画缩放，保持 `char_w` 与 `row_h` 绝对恒定稳态，杜绝视线干扰与排版跳动。
- **Sakura Editor 体验深度对齐**：
  - 准确定位 CJK 宽字符（占 2 列）与制表符 Tab，横向选区自由延伸至超出短行末尾的空白虚拟列，提供极其顺滑的纵向列编辑手感。
- **短行自动填充空格对齐**：
  - 在纵向选区批量插入文本时，针对长度短于起始列 `c0` 的短行，内核自动向行末填充 ASCII 空格至 `c0`，确保所有插入字符在纵向完美对齐，满足批量代码插入、对齐注释与表格编辑的严苛诉求。
