## IDE1.0 v0.8.2 发行说明

### 🏛️ 一、彻底根除安装包原生 Win32 UI 残留与旗舰真 3D 赛璐珞安装向导
- **彻底去除旧式 Win32 原生对话框**：
  - 从 WiX 安装包配置中完全剔除 `WixUI_InstallDir` 对话框模板与原生灰框，彻底消除传统 Windows Installer 标题栏与原生的 `Back` / `Next` / `Cancel` 按钮。
  - MSI 升级为 100% 纯净、静默的企业级自动化分发包，绝无任何 Windows 95 时代的对话框弹窗。
- **旗舰独立自安装程序 `IDE1.0_Setup.exe` 升级生效**：
  - 无边框视口渲染（`.with_decorations(false)`），全自绘美漫行动条标题栏、拖动把手与最小化/关闭控制钮，0 原生控件残留。
  - **真 3D 赛璐珞渲染引擎**：搭载 48 颗 3D 粒子星尘涡旋、倾斜双环能量共振轨道、旋转美漫光芒、爱奥尼古典立柱与正二十面体晶石 360° 交互式拖拽观察，配以 Installing 曲速流线与 Finished 庆典彩屑礼花。
  - 支持全自动物理释放、桌面及开始菜单快捷方式注入与系统 PATH 环境变量写入。

### 📝 二、便笺支持 Markdown 模式、富文本元素与可编辑预览
- **源码编辑 / 渲染预览双模即时切换**：
  - 顶部栏新增 `👁️ 预览 / ✏️ 源码` 模式切换按钮，支持全局快捷键 **`Ctrl+M`**（macOS 为 `Cmd+M`）极速切换。
- **深度复用 IDE 原生 Markdown 引擎（`md_view` & `markdown`）**：
  - 自动适配便笺纸多样色彩主题（便签黄、薄荷绿、樱花粉、晶透蓝、紫罗兰、炭黑等）。
  - **交互式待办清单（Checklist）**：预览模式下直接点击 `- [ ]` 复选框即可切换为 `- [x]` 并同步持久化。
  - **就地点击编辑（In-place Click-to-Edit）**：在预览模式下点击特定内容块快速就地微调。
  - **外部超链接直达**：点击便笺中的超链接直接调用系统浏览器打开。
- **原生 Markdown 工具栏与快捷模板插入**：
  - 新增 `### 标题`、`📊 Markdown 表格`（四列标准对齐格式）、`💻 代码块` 一键插入模板按钮。
- **数据向下向前全兼容**：兼容用户已有的 `%APPDATA%\IDE1.0 Fast\sticky_notes.json` 数据，永不丢失笔记。

### 💻 三、终端直控交互与 PowerShell 权限对齐
- **终端内直接交互控制**：消除割裂的底部独立输入框与「输入命令, Enter 执行」提示，将命令行提示符 `PS <dir>> ` 与输入完全融入终端控制台视图。
- **完整 PowerShell 能力对齐**：支持历史记录回溯（`↑` / `↓`）、Tab 键文件名与路径自动补全、`Ctrl+C` 取消当前输入 / 中断、`Ctrl+L` 极速清屏。
- **管理员与普通用户权限严格对齐与视觉显化**：
  - IDE 以管理员身份启动时终端自动继承管理员 Token，拥有真实管理员特权；普通用户启动时终端拥有标准权限。
  - 终端工具栏提供明确的 `🛡️ 管理员` / `👤 标准用户` 状态指示徽章。

### 🔍 四、Ctrl 滚轮缩放、右下角 Zoom 控制与全选方向键对齐
- **Ctrl + 滚轮字号平滑缩放**：主编辑区按住 Ctrl 滚动鼠标滚轮可实时微调字号（8.0px ~ 40.0px），配置自动持久化。
- **状态栏右下角 Zoom 控制 UI**：新增 `[－] 🔍 100% [＋]` 控件，支持快捷缩放与一键点击恢复默认字号。
- **全选方向键收缩对齐 Sakura**：全选状态下按 `↑` / `←` 立即收缩到起点 `(0, 0)` 并清空选区；按 `↓` / `→` 立即收缩到末尾并清空选区。
- **Alt 纵向选区恒定间距与短行补空格**：彻底消除选区缩放动画抖动，短行自动填充空格对齐。
