## IDE1.0 v0.6.9 发行说明

### 🎨 一、安装向导美漫卡通（Pop-Art & Cel-Shaded）全景重塑
- **美漫卡通视觉语法**：全面废弃原生安装界面与现代扁平向导，引入粗黑实体墨线外框（2.5px）、零羽化纯黑硬阴影（4px）、本戴半色调网点阵（Ben-Day Screentone Dots）、spiky 爆发星标（`POW!` / `FAST!`）以及带尾尖对白气泡。
- **古典爱奥尼台座与赛璐珞晶体**：左侧英雄展台呈现古希腊爱奥尼大理石石柱（带涡卷与金黄希腊回纹饰带），其上承托几何切面断层高对比分色的 3D 赛璐珞钻石水晶。
- **机械下陷触觉按键反馈**：所有交互卡片与按钮在鼠标按下时坐标下移 `+2.0px, +2.0px`，阴影缩短，呈现实体美漫开关的真实物理触觉感。
- **WiX MSI 原生安装包位图对齐**：使用 `generate_comic_art.py` 生成 24-bit RGB 美漫向导位图（493x58 `banner.bmp`、493x312 `dialog.bmp`），原生安装包同步换装。

### ⚡ 二、编辑器核心与交互增强
- **Alt 纵向选取列间距优化**：按住 Alt 纵向选取时，行间距保持稳定不变，横向列间距平滑拉大 8px，提供高可视性的矩阵选区定位辅助。
- **Markdown 与 .NEMA 专属折叠工具栏**：在右侧展开 MD 预览或 NEMA 视图时动态显现顶部专属工具条，关闭预览时栏位自动收起隐藏，最大化正文可视区域。
- **透明主题 60% 深度透视与防穿透**：水晶与玻璃透明主题本体透明度提升至 60%，下拉菜单与悬浮菜单强制设置为纯色不透明背景，字符支持动态反色自适应。
- **Markdown 与 NEMA 图表自适应宽度**：Markdown 表格与 NEMA 拓扑画布宽度自适应容器，超宽复杂图表自动激活底部横向滚动条，杜绝内容截断。
- **便笺文字内边距（Padding）防截断**：优化便笺内边距排版，消除文字被便笺窗口边界截断的问题。

### 🛠️ 三、全新 GitHub Actions CI/CD 流水线
- **CI 流水线（ci.yml）**：Windows & Ubuntu 跨平台自动化质量门禁，覆盖 `cargo fmt --check`、`cargo check`、`cargo clippy -D warnings` 与 1100+ 项测试套件。
- **CD 流水线（release-windows.yml）**：代码推标签时自动在 Windows 环境编译 `--release` 二进制、打包 WiX MSI、生成 SHA256 校验和并自动挂载到 GitHub Releases。
