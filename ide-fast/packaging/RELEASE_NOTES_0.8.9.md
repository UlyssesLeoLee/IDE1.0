# IDE1.0 v0.8.9 — 日志安全清理与进度条 · 崩溃专属反馈 · 悬停文字反色彻底修复 · 停靠区折叠手柄重塑 · 次世代透明水晶主题统一

## 1. 退出时日志自动清理与美漫进度条
- **7天过期日志安全清理 (`lifecycle.rs`)**：
  - 点击关闭窗口退出应用时，后台自动扫描并清理超过 7 天的历史日志文件与崩溃转储。
  - 限制最大清理超时（3s）或完成即刻退出，绝不阻碍正常关机与退出体验。
- **美漫风格退出模态与进度条**：
  - 主线程弹出带有黑曜钛金、赛璐珞高光与坚固外框的美漫进度条模态窗口，实时呈现清理文件进度与日志瘦身字节数。
- **UTF-8 安全截断**：
  - 采用 `truncate_log_filename` 字符边界安全截断，彻底消除切片越界与 Panic 隐患。

## 2. 崩溃诊断专属「反馈问题」与 GitHub Issues 联动
- **专属定制操作按钮 (`diag_log.rs`)**：
  - 启用 Windows ComCtl32 v6 视觉样式清单，将未捕获异常的系统弹窗改用专属 `OkCancelCustom("反馈问题", "关闭")`。
  - 用户点击「反馈问题」即时调用系统默认浏览器打开 GitHub Issues 页面，并自动预填版本环境、错误详情与日志路径。
- **三语 I18N 深度支持 (`i18n.rs`)**：
  - 补齐反馈弹窗中文、英文、日文专属文本与错误分类提示，告别乱码与冷冰冰的 Yes/No 语义。

## 3. 悬停文字动态反色与交互细节全面治理
- **菜单与控件悬停高对比度反色 (`menuui.rs`, `btnstyle.rs`)**：
  - 彻底解决顶部下拉菜单（分割窗口、全屏等按钮）悬停无视觉反馈、聊天顶部 Agent 下拉菜单悬停文字不反色的视觉缺陷。
  - 引入 `composite_over` 背景感知计算，在半透明水晶、浅色和深色主题下动态推导悬停文字的高对比度反色。
  - 清理强制覆盖的 `override_text_color = None` 干扰，恢复主题自然流转。

## 4. 停靠区折叠手柄重塑与聊天界面优化
- **内侧边缘腰部折叠把手 (`docks.rs`, `titlebar.rs`)**：
  - 左右与底部停靠区面板（文件树、AI聊天、Markdown预览、NEMA预览）统一采用腰部居中折叠把手。
  - 展开后折叠手柄自适应移动到展开窗口的内侧一边的边缘（紧邻代码编辑区），符合标准 IDE 折叠交互直觉。
- **全员统筹调度默认展示与极简紧凑顶栏**：
  - 聊天界面默认进入「全员协调调度界面」，移除冗余的返回精准控制切换逻辑。
  - 模型与接口设置统一移至光波统筹右侧，改用精致齿轮图标 (`⚙`) 紧凑呈现，有效释放顶部纵向空间。

## 5. 次世代透明水晶主题统一
- **双主题合璧 (`glass_render.rs`, `app.rs`)**：
  - 将原透明玻璃 (`theme-clear`) 与透明水晶 (`theme-crystal`) 各取所长，深度融合成全新的水晶质感透明主题。
- **增强型字符级动态反色与多层光学棱镜焦散**：
  - 升级 `adapt_char_color` 字符着色器，保留色彩色相的同时在浅色与光晕背景下实现防眩光高对比度呈现。
  - 多层光学焦散背板渲染，集成双发光边缘与细微棱镜光泽，兼顾极客质感与视觉美学。

## 6. 插件沙箱错误防护与死代码清理
- **插件错误反馈弹窗 (`plugin_ui.rs`)**：
  - 修复插件文档关系图点击缺失响应问题，新增插件宿主解析与沙箱错误专用模态弹窗，对禁用状态实施防护拦截与指引。
- **单代理死代码消除 (`aichat.rs`)**：
  - 彻底清理旧版遗留的单代理聊天死代码及未使用的枚举分支，包体与运行时内存开销进一步降低。
